# 盯盘关键位提醒 实现计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 一个独立跑的盯盘守护进程，盘中每分钟检查持仓价格，接近或触及关键价位时推送 Telegram 提醒。

**Architecture:** 五个纯函数模块（关键位计算、交易时段、实时报价、报警判定、推送）+ 一个主循环。业务逻辑全是不碰网络、不碰数据库的纯函数，取数和推送只在边界上，所以绝大部分逻辑能用固定数据测透。进程独立于 MCP 服务，互不拖累。

**Tech Stack:** Python 3、psycopg2（经 `db/pg.py`）、urllib（复用 `core/uw.py` 和 `core/akshare.py`）、pytest。**不引入任何新依赖**——不装 apscheduler、不装 requests、不装 python-telegram-bot。

**Spec:** `docs/superpowers/specs/2026-09-04-盯盘关键位提醒-design.md`

## Global Constraints

这些是整个仓库的硬规矩，每个任务都隐含包含。违反其中任何一条都在这个代码库里真实炸过。

**数据库（见 `CLAUDE.md` 的「Five rules every query must follow」）**

1. **占位符是 `%s`，不是 `?`**。这里是 psycopg2 不是 DuckDB。留一个 `?` 会报 `syntax error at or near "?"`。
2. **每个查市场数据的语句都必须带 `market` 条件**。`stock_ohlcv_daily` 一张表里装着 275 万行美股 + 105 万行 A 股，漏掉 `market` 会静悄悄把 A 股混进美股结果。
3. **绝不用关联子查询取最新日期**。`o.date = (select max(date) ...)` 实测是 275 万行顺序扫描（约 6.7 秒）。少数几只票就用「按票 `order by date desc limit N`」的索引扫描。
4. 本仓库只写三张表：`user_watchlist`、`user_positions`、`analysis_history`。**本功能一张都不写**，只读，走 `db/pg.py` 的只读账号。

**比率字段的量级（见 `CLAUDE.md` 的「百分点 vs 小数」）**

数据库里 `dist_ma20_pct` 这类列存的是**小数**（`0.0318` 代表 3.18%），而 `core/snapshot.py` 对外交出来的是**百分点**（`3.18`）。本功能**全程直接读 `stock_ohlcv_daily` 原始日线自己算，不经过 snapshot**，所以内部一律用**小数**（`0.01` = 1%），只在拼推送文案时乘 100。这个坑在本仓库炸过三次。

**测试**

- 跑测试：`.venv/Scripts/python.exe -m pytest tests/ -q`
- `tests/conftest.py` 默认把 `core.akshare._get` 和 `core.uw._fetch` 换成抛异常的桩。**新写的取数代码必须承诺「失败返回空，不抛异常」**，否则被这道拦截打红。
- 数据库不拦，测试直接连真 Postgres 只读账号，这是有意设计。
- 绝不在测试里真发 Telegram 消息，`core.notify._post` 必须可打桩。

**代码风格**

- 全中文注释，解释**为什么**这么写，不是复述代码在做什么。
- 模块级常量用 `#:` 开头的注释说明取值理由。
- 新模块放 `core/`，主循环放仓库根目录。

**不做的事（设计文档第九节）**

不盯 155 只自选、不做夜间静音、不做汇总推送、不建数据库表、不碰 `tt-data-hub`。

### Task 1: `core/levels.py` — 关键位计算

整个功能的核心。设计文档第四节记录了三版演进：第一版用最高价找位，被 8/28 那根长上影线（冲到 66.69 又全吐回来收 64.04）盖住了真正的阻力 64.84，导致 09-04 一声不响。

**Files:**
- Create: `core/levels.py`
- Test: `tests/test_core_levels.py`

**Interfaces:**
- Consumes: 无（纯函数，输入是日线列表）
- Produces:
  - `local_extremes(bars: list[dict], wing: int, field: str, kind: str) -> list[tuple[datetime.date, float]]`

```python
# -*- coding: utf-8 -*-
"""从日线算「关键价位」——头顶的阻力和脚下的支撑。

## 为什么用收盘价找位，不用最高价

这是本模块最重要的一条规则，也是设计阶段第一版翻车的原因。

601138 在 2026-08-28 冲到 66.69 又全吐回来收在 64.04（一根长上影线）。
用「近 N 天最高价」找关键位，66.69 会把下面真正的阻力——8/31 收在
64.84 那个位置——整个盖住。结果是 09-04 那天价格冲到 65.30 撞上真正的
坎又跌回来，程序**一声都不会响**。

66.69 只是一瞬间摸到就吐光的价，它不构成阻力。**市场真正认可、
能收得住的价才是坎。** 所以本模块一律用 close 找局部极值。

## 三个尺度

一个坎不够用：只看半年大高点会漏掉近期的小坎，只看近期又会漏掉
远处的大压力。所以近、中、远各取一档，再按距离筛掉够不着的。

## 单位约定

**这个模块内部一律用小数**（`0.01` 表示 1%），不用百分点。
`CLAUDE.md` 记着这个仓库因为百分点/小数混用炸过三次，
所以这里把话说死：进来的是小数，出去的也是小数，
只有拼推送文案的时候才乘 100。
"""
import datetime

#: 近档窗口：最近 25 个交易日，前后各 2 天判局部高低点。
#: 25 天约一个半月，够覆盖「最近这一波」的高低点；wing 取 2 是因为
#: A 股一周 5 个交易日，前后各 2 天正好是「这一周里最高的那天」。
NEAR_WIN, NEAR_WING = 25, 2

#: 远档窗口：半年，前后各 5 天。wing 更大是为了只留真正显著的顶和底。
FAR_WIN, FAR_WING = 120, 5

#: 远档的位还要被历史反复测试过至少这么多次才算数。
#: 只被碰过一次的价位是偶然，不是坎。
FAR_MIN_TOUCHES = 2

#: 两个位相差多少以内算同一道坎（小数）。1.2% 是实测值：
#: 601138 的 64.84 和 65.00 明显是同一道坎，相差 0.25%；
#: 而 64.84 和 67.42 是两道，相差 4%。1.2% 把这两种情况分得开。
MERGE_BAND = 0.012

#: 离现价超过这么远的位就不盯了（小数）。12% 是一天之内够不着的距离，
#: 盯了只是浪费——每多盯一个位就多一份误报的机会。
MAX_DIST = 0.12

#: 上下各只留最近的几个位。
KEEP_EACH = 2

#: 预警线默认往回退多少（小数）。这个值是比出来的：
#: 601138 在 2026-09-04 昨收 63.20、开盘 63.84，
#: 退 2% 的预警线落在 63.54，**开盘就已经越过**，等于一开盘就叫；
#: 退 1% 落在 64.19，盘中真涨上去才触发，正合适。
DEFAULT_WARN_DIST = 0.01


def local_extremes(bars: list[dict], wing: int, field: str,
                   kind: str) -> list[tuple[datetime.date, float]]:
    """找局部极值：前后各 `wing` 天都不超过（或不低于）它的那些天。

    `field` 一般传 "close"——理由见模块文档。开头和结尾各 `wing` 根
    因为窗口不完整，没法判断，直接跳过。
    """
    out = []
    for i in range(wing, len(bars) - wing):
        value = bars[i].get(field)
        if value is None:
            continue
        window = [bars[j].get(field) for j in range(i - wing, i + wing + 1)]
        if any(w is None for w in window):
            continue
        if (kind == "high" and value >= max(window)) or \
           (kind == "low" and value <= min(window)):
            out.append((bars[i]["date"], value))
    return out


def touch_count(bars: list[dict], price: float, band: float = 0.01) -> int:
    """这个价位历史上被测试过几次——有几天的高低区间罩住了它。

    被反复测试过的价位才是真的坎；只碰过一次的是偶然。
    """
    lo, hi = price * (1 - band), price * (1 + band)
    return sum(1 for b in bars
               if b.get("low") is not None and b.get("high") is not None
               and b["low"] <= hi and b["high"] >= lo)


def merge_levels(items: list[dict], reverse: bool) -> list[dict]:
    """挨得太近的位合并成一个，只保留先到的那个。

    不合并的话同一道坎会报好几次——64.84 和 65.00 实际上是同一个位置。
    `reverse=False` 用于阻力（价格升序，离现价近的在前），
    `reverse=True` 用于支撑（价格降序）。
    """
    if not items:
        return []
    ordered = sorted(items, key=lambda x: x["price"], reverse=reverse)
    out = [ordered[0]]
    for item in ordered[1:]:
        if abs(item["price"] - out[-1]["price"]) / out[-1]["price"] >= MERGE_BAND:
            out.append(item)
    return out


def trim(items: list[dict], keep: int = KEEP_EACH) -> list[dict]:
    """只留最近的几个位。列表必须已经按「离现价从近到远」排好。"""
    return items[:keep]


def warn_line_of(price: float, side: str, warn_dist: float) -> float:
    """预警线：阻力往下退，支撑往上退。

    不能等价格摸到关键位才叫——那时人可能在开会、在吃饭，
    等看到手机它已经冲上去又掉下来了。提前响才有时间反应。
    """
    return price * (1 - warn_dist) if side == "resistance" \
        else price * (1 + warn_dist)


def compute(bars: list[dict], warn_dist: float = DEFAULT_WARN_DIST) -> dict:
    """从日线算出该盯的关键位。

    `bars` 按日期正序，最后一根最新，每行要有 date/open/high/low/close/volume。
    数据不够长就返回空——窗口不完整时算出来的位不可信，宁可不报。

    返回 `{"resistance": [...], "support": [...]}`，每个位形如：
        {"price": 64.84, "label": "近期高收08-31",
         "warn_line": 64.19, "side": "resistance"}
    """
    if len(bars) < FAR_WIN + FAR_WING:
        return {"resistance": [], "support": []}

    last_close = bars[-1].get("close")
    if not last_close:
        return {"resistance": [], "support": []}

    resistance, support = [], []

    # 近档：最近 25 天的收盘价局部高低点
    near = bars[-NEAR_WIN:]
    for day, value in local_extremes(near, NEAR_WING, "close", "high"):
        resistance.append({"price": value,
                           "label": "近期高收%s" % day.strftime("%m-%d")})
    for day, value in local_extremes(near, NEAR_WING, "close", "low"):
        support.append({"price": value,
                        "label": "近期低收%s" % day.strftime("%m-%d")})

    # 中档：20 日最高/最低收盘
    mid = bars[-20:]
    mid_closes = [b["close"] for b in mid if b.get("close") is not None]
    if mid_closes:
        resistance.append({"price": max(mid_closes), "label": "20日最高收"})
        support.append({"price": min(mid_closes), "label": "20日最低收"})

    # 远档：半年局部高低点，且被测试过至少 2 次
    far = bars[-FAR_WIN:]
    for day, value in local_extremes(far, FAR_WING, "close", "high"):
        if touch_count(far, value) >= FAR_MIN_TOUCHES:
            resistance.append({"price": value,
                               "label": "半年高%s" % day.strftime("%m-%d")})
    for day, value in local_extremes(far, FAR_WING, "close", "low"):
        if touch_count(far, value) >= FAR_MIN_TOUCHES:
            support.append({"price": value,
                            "label": "半年低%s" % day.strftime("%m-%d")})

    # 方向和距离过滤：阻力必须在现价之上、支撑在现价之下，且都在 12% 以内
    resistance = [x for x in resistance
                  if last_close < x["price"] <= last_close * (1 + MAX_DIST)]
    support = [x for x in support
               if last_close * (1 - MAX_DIST) <= x["price"] < last_close]

    resistance = trim(merge_levels(resistance, reverse=False))
    support = trim(merge_levels(support, reverse=True))

    for item in resistance:
        item["side"] = "resistance"
        item["warn_line"] = warn_line_of(item["price"], "resistance", warn_dist)
    for item in support:
        item["side"] = "support"
        item["warn_line"] = warn_line_of(item["price"], "support", warn_dist)

    return {"resistance": resistance, "support": support}
```

```python
# -*- coding: utf-8 -*-
"""判断此刻是哪个市场的哪个交易时段。

## A股只有盘中，美股有盘前盘后

这是两个市场最大的区别。合起来一天要盯 20 小时，
只有北京时间 08:00-09:30 和 11:30-13:00 是空的。

    09:30-11:30   A股上午
    13:00-15:00   A股下午
    16:00-21:30   美股盘前     （夏令时）
    21:30-04:00   美股常规     ← 成交量占 80% 的主战场
    04:00-08:00   美股盘后

**冬令时美股三段各顺延 1 小时**，所以边界必须按日期算，不能写死。
美国夏令时是 3 月第二个周日到 11 月第一个周日。

## 盘前为什么要区别对待

实测 AAPL 连续三天，盘前成交量只占全天的 1.21%~2.20%
（常规 75%~81%，盘后 17%~23%）。几百股就能把价格打出去一大截，
这时候的「突破」极可能是假的。所以盘前要更多采样点确认。

## 一律用 UTC 算

传进来的时刻必须带时区。内部换算成北京时间（A股）和美东时间（美股），
不依赖运行机器的本地时区——服务器时区改了不该影响判断。
"""
import datetime

#: 北京时间。A股没有夏令时，固定 +8。
CN_TZ = datetime.timezone(datetime.timedelta(hours=8))

#: A股的两段，北京时间的「几点几分」用分钟数表示（9:30 = 570）。
CN_SPANS = ((9 * 60 + 30, 11 * 60 + 30), (13 * 60, 15 * 60))

#: 美股三段，**美东当地时间**的分钟数。冬夏令时的差别体现在
#: 美东和 UTC 的偏移上（见 _us_tz），所以这张表本身不用管。
US_SPANS = {
    "us_pre": (4 * 60, 9 * 60 + 30),       # 04:00-09:30
    "us_rth": (9 * 60 + 30, 16 * 60),      # 09:30-16:00
    "us_post": (16 * 60, 20 * 60),         # 16:00-20:00
}

#: 各时段要连续几个采样点确认才算真触发。
#: 盘前流动性差（只占全天成交量 1%~2%），几百股就能打出一个假价格，
#: 所以要求更多确认。
CONFIRM_TICKS = {"us_pre": 3, "default": 2}

#: 各时段全天有多少分钟——盘中量比按时间折算时要用。
#: A股 4 小时 = 240 分钟，美股常规 6.5 小时 = 390 分钟。
SESSION_MINUTES = {"cn": 240, "us_rth": 390}


def _nth_weekday(year: int, month: int, weekday: int, n: int) -> datetime.date:
    """某年某月的第 n 个星期几。weekday 用 Monday=0 的口径，6 是周日。"""
    first = datetime.date(year, month, 1)
    offset = (weekday - first.weekday()) % 7
    return first + datetime.timedelta(days=offset + 7 * (n - 1))


def us_is_dst(day: datetime.date) -> bool:
    """这一天美国是不是夏令时。

    规则：3 月第二个周日开始，11 月第一个周日结束。
    切换发生在当地凌晨 2 点，但对本模块来说按天判断就够——
    那个时刻三个时段都不在交易，差一小时不影响任何判断。
    """
    start = _nth_weekday(day.year, 3, 6, 2)
    end = _nth_weekday(day.year, 11, 6, 1)
    return start <= day < end


def _us_tz(day: datetime.date) -> datetime.timezone:
    """美东时区。夏令时 UTC-4，冬令时 UTC-5。"""
    hours = -4 if us_is_dst(day) else -5
    return datetime.timezone(datetime.timedelta(hours=hours))


def _in_span(minutes: int, span: tuple) -> bool:
    return span[0] <= minutes < span[1]


def current(now_utc: datetime.datetime) -> list[str]:
    """此刻正在进行的交易时段，可能不止一个，都不在就返回空列表。

    周末一律不算。节假日不判断——多跑几轮的成本只是几个请求，
    不值得为此维护一张年年要更新的节假日表。
    """
    out = []

    cn_now = now_utc.astimezone(CN_TZ)
    if cn_now.weekday() < 5:
        minutes = cn_now.hour * 60 + cn_now.minute
        if any(_in_span(minutes, span) for span in CN_SPANS):
            out.append("cn")

    us_tz = _us_tz(now_utc.date())
    us_now = now_utc.astimezone(us_tz)
    if us_now.weekday() < 5:
        minutes = us_now.hour * 60 + us_now.minute
        for name, span in US_SPANS.items():
            if _in_span(minutes, span):
                out.append(name)

    return out


def is_premarket(name: str) -> bool:
    """是不是盘前——盘前的信号要更多确认，且不判「有效突破」。"""
    return name == "us_pre"


def confirm_ticks(name: str) -> int:
    """这个时段要连续几个采样点确认。"""
    return CONFIRM_TICKS.get(name, CONFIRM_TICKS["default"])
```

```python
走新浪的 `stock_zh_a_spot`，一趟 15 秒拿回 5555 只，**盯 1 只和盯

单票 11.4 秒，但并发有效：6 只一起拉只要 13.8 秒。

## 失败一律返回空，不抛异常

任何一路挂了都只能影响那一路，不能让整轮盯盘死掉。
`tests/conftest.py` 默认把底层取数换成抛异常的桩，正是靠这条约定

import math

from core import akshare, uw

_SINA_FIELDS = {
    "最新价": "last", "最高": "high", "最低": "low",
    "今开": "open", "昨收": "prev_close", "成交量": "volume",
}


def _f(value):
    """转成有限浮点数，转不动或是 NaN/Inf 返回 None。

    必须挡住 NaN：`float('nan')` 既不是假值也不满足比较，
    放过去会一路算进关键位判定。
    """
    try:
        num = float(value)
    except (TypeError, ValueError):
        return None
    return num if math.isfinite(num) else None


def cn_quotes(tickers: list[str]) -> dict[str, dict]:
    """A股实时价。一个请求拿回全市场，再从里面挑我们要的票。"""
    if not tickers or not akshare.available():
        return {}
    wanted = {}
    for ticker in tickers:
        sina = akshare.to_sina(ticker)      # 600519.SH -> sh600519
        if sina:
            wanted[sina] = ticker
    if not wanted:
        return {}

    try:
        rows = akshare._get("stock_zh_a_spot", {})
    except Exception:
        return {}
    if not isinstance(rows, list):
        return {}

    out = {}
    for row in rows:
        code = str(row.get("代码", "")).strip().lower()
        ticker = wanted.get(code)
        if not ticker:
            continue
        quote = {"session": "cn", "source": "akshare"}
        for cn_key, key in _SINA_FIELDS.items():
            quote[key] = _f(row.get(cn_key))
        if quote.get("last"):
            out[ticker] = quote
    return out


def us_quotes(tickers: list[str]) -> dict[str, dict]:
    """美股实时价。并发拉 1 分钟线，取最新一根当现价。"""
    if not tickers or not uw.available():
        return {}
    # 指数代码喂给 /api/stock/... 一律 422，发出去只是白等十几秒
    paths = {"/api/stock/%s/ohlc/1m" % t: t
             for t in tickers if not t.startswith("^")}
    if not paths:
        return {}

    try:
        payloads = uw.get_many(list(paths.keys()))
    except Exception:
        return {}

    out = {}
    for path, rows in (payloads or {}).items():
        ticker = paths.get(path)
        if not ticker or not isinstance(rows, list) or not rows:
            continue
        newest = rows[0]                   # UW 是倒序，第一行最新
        last = _f(newest.get("close"))
        if not last:
            continue
        highs = [h for h in (_f(r.get("high")) for r in rows) if h]
        lows = [l for l in (_f(r.get("low")) for r in rows) if l]
        out[ticker] = {
            "last": last,
            # 当天最高最低要扫过所有分钟线——「假突破」判定要用盘中最高价
            "high": max(highs) if highs else last,
            "low": min(lows) if lows else last,
            "open": _f(rows[-1].get("open")) or last,
            "prev_close": None,            # 分钟线里没有昨收，本功能用不到
            "volume": _f(newest.get("total_volume")) or 0.0,
            "session": newest.get("market_time") or "r",
            "source": "uw",
        }
    return out


def get(tickers_by_market: dict[str, list[str]]) -> dict[str, dict]:
    """取一批票的实时价，按市场自动分流。

    某一个市场挂了不影响另一个——这是盯盘进程能一直活着的前提。
    """
    out = {}
    try:
        out.update(cn_quotes(tickers_by_market.get("CN") or []))
    except Exception:
        pass
    try:
        out.update(us_quotes(tickers_by_market.get("US") or []))
    except Exception:
        pass
    return out
```

```python
# -*- coding: utf-8 -*-
"""把「价格 + 关键位 + 时段」变成「要不要叫醒用户」。

## 碰到价不等于要动手

同样是碰到 64.84，冲过去站住和冲过去掉下来是完全相反的两件事。
所以碰到之后还要看它怎么走，分成四种结果，只有三种值得推送：

    有效突破   收在关键位上方 + 放量      → 推
    假突破     盘中越过了又跌回下方        → 推   ← 601138 在 09-04 就是这个
    跌破       收在支撑位下方             → 推
    站上没量 / 受阻回落 / 探底守住          → 不推，是流水账

设计阶段实测：把后三种也推出去，45 个交易日里 73% 的天都在响；
只推前三种，降到 31%。一个吵的提醒工具，用户两天就静音，等于没有。

## 预警必须是「穿越触发」

不能等价格摸到关键位才叫——那时人可能在开会、在吃饭。每个关键位
往回退 1% 画一条预警线，但**只在价格从远处走过来、穿过那条线的
一刻才报**；如果价格本来就在附近磨蹭，一声不响。
这一条把预警从 27 条压到 17 条，是降噪最有效的一招。

## 盘中量比必须按时间折算

这是实现时最容易翻车的地方。盘中成交量是累计值，上午 10 点只跑了
半小时，直接除以 20 日均量**永远偏低**，结果「有效突破」这一类
**永远判不出来**。必须按已开盘的时间比例折算。

开盘头 15 分钟分母太小、量比剧烈跳动，那段时间不做突破判定，
只判「假突破」和「跌破」。

## 单位一律用小数

`0.005` 表示 0.5%。见 `core/levels.py` 的同款说明。
"""
import datetime

from core import session as session_mod

#: 只有这三类值得打扰用户，其余是流水账。
ACTIONABLE = ("有效突破", "假突破", "跌破")

#: 进到关键位的 ±0.5% 以内就算「碰到」。
TOUCH_BAND = 0.005

#: 同一个位的到位判定，多少天内不重复。
FIRE_COOLDOWN_DAYS = 5

#: 同一个位的接近预警，多少天内不重复。预警冷却更长——
#: 「快到坎了」这件事说一遍就够，说三遍就是噪音。
WARN_COOLDOWN_DAYS = 10

#: 量比到这个倍数才算「放量」。
VOL_CONFIRM = 1.2

#: 开盘头多少分钟不做突破判定（量比分母太小，跳动剧烈）。
SKIP_OPEN_MINUTES = 15

#: 保险丝：每只票每天最多推几条、全天总共最多几条。
#: 实测频率是每只票每天 0.78 条、7 只持仓一天 5~6 条，离这两个数很远。
#: 它们不是用来调节奏的，是防止算法出 bug 时把用户的手机炸掉——
#: 真到了上限，说明有别的东西坏了。
MAX_PER_TICKER_PER_DAY = 4
MAX_PER_DAY = 25


def intraday_volume_ratio(volume: float, avg_volume: float,
                          elapsed_minutes: float,
                          session_name: str) -> float | None:
    """盘中量比，按已开盘时间折算。算不了就返回 None。

    不折算的话，开盘半小时的成交量除以全天均量永远是个很小的数，
    「有效突破」永远判不出来——这是设计文档 5.1 节点名的翻车点。
    """
    total = session_mod.SESSION_MINUTES.get(session_name)
    if not total or not avg_volume or elapsed_minutes < SKIP_OPEN_MINUTES:
        return None
    expected = avg_volume * (min(elapsed_minutes, total) / total)
    if expected <= 0:
        return None
    return volume / expected


def classify(side: str, price: float, quote: dict,
             vol_ratio: float | None, premarket: bool) -> str | None:
    """碰到这个位之后走成了什么样。不值得推的返回 None。"""
    last = quote.get("last")
    if not last:
        return None

    if side == "resistance":
        high = quote.get("high") or last
        if last > price:
            # 盘前不判「有效突破」：成交量只占全天 1%~2%，量能不可比
            if premarket or vol_ratio is None:
                return None
            return "有效突破" if vol_ratio > VOL_CONFIRM else None
        if high > price:
            return "假突破"        # 冲过去了又跌回来
        return None                # 受阻回落，是流水账

    if last < price:
        return "跌破"
    return None                    # 探底守住，是流水账


def crossed_warn_line(side: str, warn_line: float,
                      prev_last: float | None, now_quote: dict) -> bool:
    """价格是不是**刚刚**穿过预警线（从远处走过来）。

    在预警线附近来回磨蹭不算——那会把同一件事报很多遍。
    没有上一个采样点（进程刚起）时不报，等下一轮。
    """
    last = now_quote.get("last")
    if not last or prev_last is None:
        return False
    if side == "resistance":
        return prev_last < warn_line <= last
    return prev_last > warn_line >= last


def _touched(side: str, price: float, quote: dict) -> bool:
    if side == "resistance":
        high = quote.get("high") or quote.get("last") or 0
        return high >= price * (1 - TOUCH_BAND)
    low = quote.get("low") or quote.get("last") or 0
    return low <= price * (1 + TOUCH_BAND)


def _key(ticker: str, price: float) -> str:
    return "%s|%.2f" % (ticker, price)


def _on_cooldown(store: dict, key: str, today: str, days: int) -> bool:
    """同一个位在冷却期内不重复报。存日期字符串，够用且好读。"""
    last_day = store.get(key)
    if not last_day:
        return False
    try:
        prev = datetime.date.fromisoformat(last_day)
        now = datetime.date.fromisoformat(today)
    except ValueError:
        return False
    return (now - prev).days < days


def evaluate(ticker: str, quote: dict, levels: dict, state: dict,
             session_name: str, avg_volume: float,
             elapsed_minutes: float, today: str | None = None) -> list[dict]:
    """算出这一轮该推的报警。会就地更新 `state`（去重用）。

    `state` 形如：
        {"fired": {"票|价": "YYYY-MM-DD"},
         "warned": {...},
         "prev_last": {"票": 上一轮的现价},
         "ticks": {"票|价": 连续命中了几次}}
    """
    if today is None:
        today = datetime.date.today().isoformat()

    premarket = session_mod.is_premarket(session_name)
    need_ticks = session_mod.confirm_ticks(session_name)
    vol_ratio = intraday_volume_ratio(
        quote.get("volume") or 0.0, avg_volume, elapsed_minutes, session_name)
    prev_last = state.setdefault("prev_last", {}).get(ticker)
    ticks = state.setdefault("ticks", {})

    out = []
    items = list(levels.get("resistance") or []) + list(levels.get("support") or [])
    for item in items:
        side, price = item["side"], item["price"]
        key = _key(ticker, price)

        # ---- 接近预警：穿过预警线的那一刻 ----
        if crossed_warn_line(side, item["warn_line"], prev_last, quote):
            if not _on_cooldown(state.setdefault("warned", {}), key,
                                today, WARN_COOLDOWN_DAYS):
                state["warned"][key] = today
                out.append({"ticker": ticker, "kind": "接近预警",
                            "price": price, "label": item["label"],
                            "side": side, "quote": quote,
                            "session": session_name})

        # ---- 到位判定：碰到之后看它怎么走 ----
        if not _touched(side, price, quote):
            ticks.pop(key, None)
            continue
        kind = classify(side, price, quote, vol_ratio, premarket)
        if kind not in ACTIONABLE:
            ticks.pop(key, None)
            continue

        # 连续命中够几次才算数——盘前要 3 次，别的 2 次。
        #
        # 计数按「位」记，**不按 kind 记**，这是有意的：价格在关键位上下
        # 来回时，同一个位的状态可能从「有效突破」变成「假突破」，
        # 而用户要知道的是**最后落在哪一边**。按位计数、报最新那次的
        # 判定，正好给出这个答案；按 kind 分开计数反而会两种都报一遍。
        ticks[key] = ticks.get(key, 0) + 1
        if ticks[key] < need_ticks:
            continue
        if _on_cooldown(state.setdefault("fired", {}), key,
                        today, FIRE_COOLDOWN_DAYS):
            continue
        state["fired"][key] = today
        ticks[key] = 0
        out.append({"ticker": ticker, "kind": kind, "price": price,
                    "label": item["label"], "side": side,
                    "quote": quote, "session": session_name})

    state["prev_last"][ticker] = quote.get("last")
    return out
```

```python
# -*- coding: utf-8 -*-
"""往 Telegram 推提醒。

## 为什么把发请求那一层单独抽出来

`_post` 是唯一真正发网络请求的函数，测试一律把它换掉。
跟 `core/uw.py` 抽 `_fetch` 是同一个理由：不这么做的话，
配了真 token 的机器上跑一次测试就会真发一条消息给用户。

## 推送失败不能把进程搞挂

盯盘是个要连跑一整天的进程。Telegram 抽风、代理断了、网络闪断，
都只能让这一条丢掉，下一轮继续。所以 `send()` 承诺不抛异常。

## 文案要说清三件事

哪只票、发生了什么、你手上有多少。缺一条用户都得再去查一次，
而盯盘提醒的全部价值就在于「不用再查」。
"""
import json
import urllib.parse
import urllib.request

import config

#: 时段代号 → 给人看的说法。盘前盘后要标出来，
#: 那时候流动性差（盘前只占全天成交量 1%~2%），信号成色不一样。
_SESSION_LABEL = {"pr": "盘前", "po": "盘后"}

#: 各类报警的第一行怎么写。
_KIND_LINE = {
    "接近预警": "快到坎了",
    "假突破": "假突破",
    "有效突破": "有效突破",
    "跌破": "跌破",
}


def available() -> bool:
    return bool(config.TG_BOT_TOKEN and config.TG_CHAT_ID)


def _pct(a: float, b: float) -> float:
    """(a-b)/b 的百分数。b 为 0 时返回 0。"""
    return (a - b) / b * 100 if b else 0.0


def format_alert(alert: dict, position: dict | None) -> str:
    """把一条报警拼成推送文案。"""
    quote = alert.get("quote") or {}
    last = quote.get("last") or 0.0
    price = alert["price"]
    kind = alert["kind"]

    head = "%s · %s" % (alert["ticker"], _KIND_LINE.get(kind, kind))
    tag = _SESSION_LABEL.get(quote.get("session") or "")
    if tag:
        head += "  [%s]" % tag
    lines = [head]

    if kind == "接近预警":
        lines.append("%.2f 是%s，现价 %.2f，还差 %.1f%%" % (
            price, alert["label"], last, abs(_pct(price, last))))
    elif kind == "假突破":
        high = quote.get("high") or last
        lines.append("冲到 %.2f 越过 %.2f（%s），没站住" % (
            high, price, alert["label"]))
        lines.append("现价 %.2f，已从高点回落 %.1f%%" % (
            last, abs(_pct(last, high))))
    elif kind == "有效突破":
        lines.append("放量站上 %.2f（%s），现价 %.2f" % (
            price, alert["label"], last))
    elif kind == "跌破":
        low = quote.get("low") or last
        lines.append("跌破 %.2f（%s），现价 %.2f，最低到过 %.2f" % (
            price, alert["label"], last, low))

    if position and position.get("avg_cost"):
        cost = float(position["avg_cost"])
        shares = float(position.get("shares") or 0)
        pnl = _pct(last, cost)
        lines.append("持仓 %g 股 · 成本 %.2f · %s %.1f%%" % (
            shares, cost, "浮盈" if pnl >= 0 else "浮亏", abs(pnl)))

    if tag == "盘后":
        lines.append("盘后流动性低，明早开盘可能反向")
    elif tag == "盘前":
        lines.append("盘前成交稀薄，开盘前仅供参考")

    return "\n".join(lines)


def _post(url: str, data: bytes, proxy: str):
    """真正发请求的那一层。异常照抛，由 `send()` 吞掉。

    单独抽出来只为一件事：测试里能整体换掉，绝不真发消息。
    """
    handler = urllib.request.ProxyHandler(
        {"http": proxy, "https": proxy} if proxy else {})
    opener = urllib.request.build_opener(handler)
    request = urllib.request.Request(
        url, data=data,
        headers={"Content-Type": "application/x-www-form-urlencoded"})
    with opener.open(request, timeout=15) as response:
        return json.loads(response.read().decode("utf-8"))


def send(text: str) -> bool:
    """推一条消息。任何失败都返回 False，**不抛异常**。

    盯盘进程要连跑一整天，一次推送失败不能让它死掉。
    """
    if not available():
        return False
    url = "https://api.telegram.org/bot%s/sendMessage" % config.TG_BOT_TOKEN
    data = urllib.parse.urlencode({
        "chat_id": config.TG_CHAT_ID,
        "text": text,
        "disable_web_page_preview": "true",
    }).encode("utf-8")
    try:
        _post(url, data, config.TG_PROXY)
        return True
    except Exception:
        return False
```

```python
# -*- coding: utf-8 -*-
"""盯盘守护进程：盘中每分钟看一眼持仓，撞上关键价位就推 Telegram。

## 为什么独立跑，不塞进 main.py

MCP 服务是给 Claude.ai 用的。用户重启它、改代码、它偶尔崩，
**都不应该让盯盘停掉**；反过来盯盘每分钟拉一轮行情，
也不该拖累 MCP 的响应。两件事的失败模式完全不同。

## 每一轮做什么

    1. 从 user_positions 读当前持仓  ← 每轮都读，不缓存
    2. 按市场分两拨取实时价
    3. 跟当天的关键位比对
    4. 触发了、且没在冷却期 → 推 Telegram

**持仓每轮都重新读**是用户明确要的：他在 Claude.ai 里加一笔仓，
下一分钟盯盘就得认；平了仓，下一分钟就不该再盯。这个查询才几行，
成本可以忽略。

## 这个进程只读数据库

读 `user_positions` 和 `stock_ohlcv_daily`，一张表都不写。

用法：
    python watchdog.py            # 一直跑
    python watchdog.py --once     # 只跑一轮，调试用
"""
import argparse
import datetime
import json
import sys
import time

import config
from core import alerts, levels, notify, quotes, session as session_mod
from db import pg

UTC = datetime.timezone.utc

#: 取多少根日线来算关键位。远档窗口要 120 根 + 前后各 5 根余量，
#: 200 根留了充分空间，也不至于把查询拖慢。
BARS_LIMIT = 200

#: 关键位一天算一次就够（它只依赖收盘数据），缓存在内存里。
#: 键是 "票|市场|日期"，换天了整个清掉。
_levels_cache: dict = {}


def empty_state() -> dict:
    # daily 形如 {"date": "2026-09-04", "total": 3, "by_ticker": {"票": 2}}，
    # 换天自动清零。它是保险丝，见 _within_daily_cap。
    return {"fired": {}, "warned": {}, "prev_last": {}, "ticks": {},
            "daily": {}}


def _within_daily_cap(state: dict, ticker: str, today: str) -> bool:
    """今天这只票、以及全天总量，还没到上限就放行，并记一笔。

    实测频率是每只票每天 0.78 条、7 只持仓一天 5~6 条，离上限很远。
    这两道闸不是用来调节奏的，是防止算法出 bug 时把用户手机炸掉——
    真撞到上限，说明有别的东西坏了。
    """
    daily = state.setdefault("daily", {})
    if daily.get("date") != today:          # 换天了，清零重来
        daily.clear()
        daily.update({"date": today, "total": 0, "by_ticker": {}})
    by_ticker = daily.setdefault("by_ticker", {})
    if daily.get("total", 0) >= alerts.MAX_PER_DAY:
        return False
    if by_ticker.get(ticker, 0) >= alerts.MAX_PER_TICKER_PER_DAY:
        return False
    daily["total"] = daily.get("total", 0) + 1
    by_ticker[ticker] = by_ticker.get(ticker, 0) + 1
    return True


def load_state(path: str) -> dict:
    """读去重状态。文件不在或坏了都返回空状态——大不了重新攒，
    绝不能因为一个 JSON 坏了就让进程起不来。"""
    try:
        with open(path, "r", encoding="utf-8") as handle:
            data = json.load(handle)
    except Exception:
        return empty_state()
    base = empty_state()
    if isinstance(data, dict):
        for key in base:
            if isinstance(data.get(key), dict):
                base[key] = data[key]
    return base


def save_state(path: str, state: dict) -> None:
    try:
        with open(path, "w", encoding="utf-8") as handle:
            json.dump(state, handle, ensure_ascii=False, indent=1)
    except Exception:
        pass          # 存不下就算了，下一轮再试，不值得中断盯盘


def load_positions() -> list[dict]:
    """当前持仓。**每轮都重新读**，不缓存。"""
    return pg.query(
        "select ticker, market, avg_cost, shares, currency "
        "from user_positions order by market, ticker")


def load_bars(ticker: str, market: str, limit: int = BARS_LIMIT) -> list[dict]:
    """一只票最近的日线，**正序**返回（最后一根最新）。

    按票 `order by date desc limit N` 走索引扫描。绝不能写成
    `date = (select max(date) ...)` 那种关联子查询——实测是 275 万行
    顺序扫描，约 6.7 秒。
    """
    rows = pg.query(
        "select date, open, high, low, close, volume "
        "from stock_ohlcv_daily "
        "where ticker = %s and market = %s "
        "order by date desc limit %s",
        (ticker, market, int(limit)))
    return list(reversed(rows or []))


def avg_volume_of(bars: list[dict], days: int = 20) -> float:
    """最近 N 根日线的平均成交量，给盘中量比当分母。"""
    vols = [float(b["volume"]) for b in bars[-days:]
            if b.get("volume") is not None]
    return sum(vols) / len(vols) if vols else 0.0


def elapsed_minutes(now_utc: datetime.datetime, session_name: str) -> float:
    """这个时段已经开了多少分钟。A股的午休不算在内。"""
    if session_name == "cn":
        now = now_utc.astimezone(session_mod.CN_TZ)
        minutes = now.hour * 60 + now.minute
        total = 0.0
        for start, end in session_mod.CN_SPANS:
            if minutes >= end:
                total += end - start
            elif minutes > start:
                total += minutes - start
        return total
    if session_name in session_mod.US_SPANS:
        tz = session_mod._us_tz(now_utc.date())
        now = now_utc.astimezone(tz)
        minutes = now.hour * 60 + now.minute
        return max(0.0, minutes - session_mod.US_SPANS[session_name][0])
    return 0.0


def _levels_for(ticker: str, market: str, today: str) -> dict:
    """关键位，一天算一次，缓存在内存里。"""
    key = "%s|%s|%s" % (ticker, market, today)
    if key not in _levels_cache:
        if _levels_cache and not any(k.endswith("|" + today)
                                     for k in _levels_cache):
            _levels_cache.clear()          # 换天了，旧的全丢掉
        bars = load_bars(ticker, market)
        _levels_cache[key] = {
            "levels": levels.compute(bars, config.WATCHDOG_WARN_DIST),
            "avg_volume": avg_volume_of(bars),
        }
    return _levels_cache[key]


def _us_session_of(quote: dict, active: list[str]) -> str:
    """美股这一刻算哪个时段。优先信 UW 分钟线自带的 market_time
    （r/pr/po），它比按时间猜准——盘前盘后的边界在数据里是现成的。"""
    mapping = {"pr": "us_pre", "r": "us_rth", "po": "us_post"}
    tag = quote.get("session")
    if tag in mapping:
        return mapping[tag]
    for name in ("us_rth", "us_pre", "us_post"):
        if name in active:
            return name
    return "us_rth"


def run_once(state: dict, now_utc: datetime.datetime | None = None) -> list[dict]:
    """跑一轮。返回这一轮推出去的报警。任何一路失败都只影响那一路。"""
    now_utc = now_utc or datetime.datetime.now(UTC)
    active = session_mod.current(now_utc)
    if not config.WATCHDOG_PREMARKET:
        active = [s for s in active if s != "us_pre"]
    if not active:
        return []

    try:
        positions = load_positions() or []
    except Exception:
        return []
    if not positions:
        return []

    us_open = any(s.startswith("us_") for s in active)
    by_market = {}
    for row in positions:
        market = (row.get("market") or "US").upper()
        if market == "CN" and "cn" not in active:
            continue
        if market == "US" and not us_open:
            continue
        by_market.setdefault(market, []).append(row["ticker"])
    if not by_market:
        return []

    try:
        quote_map = quotes.get(by_market)
    except Exception:
        return []
    if not quote_map:
        return []

    today = now_utc.astimezone(session_mod.CN_TZ).date().isoformat()
    pos_by_ticker = {r["ticker"]: r for r in positions}
    fired = []

    for ticker, quote in quote_map.items():
        row = pos_by_ticker.get(ticker)
        if not row:
            continue
        market = (row.get("market") or "US").upper()
        name = "cn" if market == "CN" else _us_session_of(quote, active)
        try:
            cached = _levels_for(ticker, market, today)
        except Exception:
            continue
        got = alerts.evaluate(
            ticker, quote, cached["levels"], state, name,
            cached["avg_volume"], elapsed_minutes(now_utc, name), today)
        for alert in got:
            if not _within_daily_cap(state, ticker, today):
                continue          # 撞到保险丝，今天这只票不再打扰
            notify.send(notify.format_alert(alert, row))
            fired.append(alert)

    return fired


def main() -> None:
    parser = argparse.ArgumentParser(description="盯盘守护进程")
    parser.add_argument("--once", action="store_true",
                        help="只跑一轮就退出，调试用")
    args = parser.parse_args()

    if not notify.available():
        sys.stderr.write(
            "没配 TG_BOT_TOKEN / TG_CHAT_ID，盯盘起来也发不出消息。\n"
            "把它们填进 .env 再跑——一个「以为在盯盘、其实什么都没发」\n"
            "的进程比没有更糟。\n")
        raise SystemExit(1)

    path = config.WATCHDOG_STATE_FILE
    state = load_state(path)

    if args.once:
        got = run_once(state)
        save_state(path, state)
        print("推了 %d 条" % len(got))
        return

    print("盯盘启动，每 %d 秒一轮。Ctrl-C 停止。" % config.WATCHDOG_INTERVAL)
    while True:
        try:
            got = run_once(state)
            if got:
                save_state(path, state)
                for alert in got:
                    print("[%s] %s %s %.2f" % (
                        datetime.datetime.now().strftime("%H:%M:%S"),
                        alert["ticker"], alert["kind"], alert["price"]))
        except KeyboardInterrupt:
            print("停止。")
            save_state(path, state)
            return
        except Exception as exc:      # 任何没想到的错都不能让进程死
            sys.stderr.write("这一轮出错，跳过：%r\n" % (exc,))
        time.sleep(config.WATCHDOG_INTERVAL)


if __name__ == "__main__":
    main()
```

## 部署（实现完成后）

部署走仓库现有的 `scripts/deploy.sh`（推 GitHub → 服务器 fetch），服务器上另起一个进程：

**上线前必须在服务器上确认两件事**：

1. `.env` 里填好了 `TG_BOT_TOKEN` / `TG_CHAT_ID` / `TG_PROXY`——本机没有这几个键，代码不猜也不去别的项目里找。
2. `AKSHARE_BASE_URL` 指向的 AKTools 上**新浪源是活的**：`curl "$AKSHARE_BASE_URL/stock_zh_a_spot" | head -c 200` 应该返回 JSON。2026-09-04 实测那台机器上东财源（`_em` 后缀）全部 500，所以代码走的是新浪那条路；哪天新浪也挂了，A 股这一路就哑了。
