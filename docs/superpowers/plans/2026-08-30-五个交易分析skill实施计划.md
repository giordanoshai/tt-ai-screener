## 全局约束

这一节的每一条都适用于下面所有任务，不再重复。

**数据库查询五条规矩**（每一条都真的把这个项目搞崩过一次，见 `db/pg.py` 的模块注释）：

1. 占位符是 `%s`，不是 `?`。写成 `?` 直接报 `syntax error at or near "?"`。
2. 查 `stock_ohlcv_daily`、`stock_ohlcv_min`、`stocks_meta`、`stock_fundamentals`
   **必须带 `market` 条件**。日线表里美股 275 万行、A股 105 万行混在一起。
3. **不用相关子查询取最新交易日**。几只票就按票 `order by date desc limit 1`
   走索引；全池扫描就先单独查出该市场的最新交易日，再等值比较。
4. `stock_fundamentals` 一只票多行（主键是 `(ticker, updated_at)`，2172 只美股散在
   31721 行里），**必须 `distinct on (ticker) ... order by ticker, updated_at desc`**。
5. `stock_ohlcv_min` 里有 **三种** 周期：`1h`、`1m`、`5m`。漏掉 `timeframe` 条件会撞上
   2000 万行 9.3GB。

**短线禁用字段**（设计文档第三节，代码里硬性禁止，不靠自觉）：

`core/snapshot.py` 的 SQL **一个都不许出现**：
`pe_ratio`、`ps_ratio`、`pb_ratio`、`peg_ratio`、`forward_pe`、`ev_to_ebitda`、
`revenue_growth_yoy`、`earnings_growth_yoy`、`gross_margin`、`operating_margin`、
`profit_margin`、`roe`、`fcf_yield`、`analyst_rating`、`analyst_target_price`、
`analyst_count`、`dividend_yield`。

`score_short()` 和 `score_short_cn()` 的函数签名里**不许有基本面参数**。任务 4 的
回归测试会用 `inspect.signature` 检查这两条，写错了测试直接红。

**例外（设计文档第三节写明）**：`next_earnings_date` 和 `market_cap` 存在
`stock_fundamentals` 里，但短线要它们避雷和过流动性门槛。这两个字段由
`core/catalyst.earnings_for()` 单独取，**只 select 这两列加 ticker**，不会顺手把整行
基本面带进来。

**降级三原则**（设计文档第八节）：

1. 任何一路数据缺失都不能让整个工具失败。缺的写进 `data_gaps`。
2. 缺数据要明写，不静默降级。评分按「实际拿到的分项」重新归一化，并记录缺了哪项。
3. 数据陈旧要检测。该市场最新交易日距今超过 3 个自然日就加陈旧警告。

**本仓库不写任何采集代码。** 不建表、不改表、不写行情数据。唯一的写操作是
`user_watchlist` / `user_positions`（已有）和 `analysis_history`（网页面板写）。

**不动的文件**：`db/pg.py`、`config.py` 的数据库部分、`ai_client.py`、
`tools/screening.py`、`skills/`、`web/`。

```python
# -*- coding: utf-8 -*-
"""Unusual Whales 实时接口客户端。

## 为什么有些数据走实时、有些走数据库

库里的期权数据一天只灌两次（美东 9:30 和 16:00），拿它「盯盘」名不副实。
所以持仓盯盘和个股分析走实时，全市场扫描走数据库——2000 多只票的均线、RSI、
ATR 库里已经算好了，查一次 0.1 秒；换成实时要调 2000 多次日线接口，
并发 20 路也要 15 分钟，在对话里等不到。

## 两个必须知道的坑

1. **必须带浏览器 User-Agent。** 代理挡在 Cloudflare 后面，Python 默认的
   `Python-urllib/3.12` 会被当成爬虫，直接 403（页面里写的是 Error 1010）。
   这跟 token 没关系，换任何鉴权写法都救不了。
2. **`/api/alerts` 返回的 `symbol` 是期权合约代码**（`NVDA261002P00190000`），
   不是股票代码。标的在 `meta.underlying_symbol` 里。实测 100 条里还有 14 条
   `potus_schedule`，`symbol` 直接是 null。想按持仓过滤必须先解出标的。

## 失败就是 None

这个模块的任何函数**都不抛异常**。取不到就返回 None，调用方据此走降级并在
`data_gaps` 里写明这一路是缺的。一个外部接口慢，不该让整个工具失败。
"""
import concurrent.futures
import json
import urllib.error
import urllib.parse
import urllib.request

import config

#: 不带这个头会被 Cloudflare 403。见模块注释。
BROWSER_UA = ("Mozilla/5.0 (Windows NT 10.0; Win64; x64) "
              "AppleWebKit/537.36 (KHTML, like Gecko) "
              "Chrome/126.0.0.0 Safari/537.36")

#: 并发取多只票时的线程数。6 只持仓一轮 4 秒左右，再高对代理不礼貌。
MAX_WORKERS = 6

#: 期权合约代码（OCC 格式）里，股票代码之后就是 6 位到期日。
#: NVDA261002P00190000 -> NVDA
_OCC_TAIL_LEN = 15


def available() -> bool:
    """有没有配密钥。没配就别调，直接走库里的数据。"""
    return bool(config.UW_API_TOKEN)


def _to_float(value, default: float = 0.0) -> float:
    """UW 把数值全用字符串返回，统一转一下。转不动就给默认值。"""
    if value is None:
        return default
    try:
        return float(value)
    except (TypeError, ValueError):
        return default


def get(path: str, params: dict | None = None,
        timeout: float | None = None) -> list[dict] | None:
    """调一个接口，返回 data 数组。任何失败都返回 None，不抛。"""
    if not available():
        return None

    url = config.UW_API_BASE + path
    if params:
        url += "?" + urllib.parse.urlencode(params)

    request = urllib.request.Request(url, headers={
        "Authorization": f"Bearer {config.UW_API_TOKEN}",
        "Accept": "application/json",
        "User-Agent": BROWSER_UA,   # 少了这行就是 403，见模块注释
    })
    try:
        with urllib.request.urlopen(
                request, timeout=timeout or config.UW_TIMEOUT) as response:
            payload = json.loads(response.read())
    except Exception:
        return None

    if isinstance(payload, list):
        return payload
    if isinstance(payload, dict):
        data = payload.get("data")
        return data if isinstance(data, list) else None
    return None


def get_many(paths: list[str],
             timeout: float | None = None) -> dict[str, list[dict] | None]:
    """并发调一批接口。键是原样的 path，取不到的那条值是 None。"""
    if not paths:
        return {}
    out: dict[str, list[dict] | None] = {}
    with concurrent.futures.ThreadPoolExecutor(
            max_workers=min(MAX_WORKERS, len(paths))) as pool:
        futures = {pool.submit(get, p, None, timeout): p for p in paths}
        for future in concurrent.futures.as_completed(futures):
            out[futures[future]] = future.result()
    return out


def flow_alerts(ticker: str, limit: int = 50) -> list[dict] | None:
    """一只票近期的期权异动。实测 3.6 秒。"""
    return get(f"/api/stock/{ticker}/flow-alerts", {"limit": limit})


def flow_alerts_many(tickers: list[str],
                     limit: int = 50) -> dict[str, list[dict] | None]:
    """一批票的期权异动，并发取。键是股票代码。"""
    paths = {f"/api/stock/{t}/flow-alerts?limit={limit}": t for t in tickers}
    raw = get_many(list(paths))
    return {paths[path]: rows for path, rows in raw.items()}


def alerts(limit: int = 100) -> list[dict] | None:
    """用户自己配的实时警报流。实测 12~14 秒，是最慢的一个接口。"""
    return get("/api/alerts", {"limit": limit})


def news_headlines(limit: int = 50) -> list[dict] | None:
    """最近的新闻标题。只有 is_major 布尔值，没有 High/Medium/Low 分级。"""
    return get("/api/news/headlines", {"limit": limit})


def underlying_of(alert: dict) -> str | None:
    """从一条警报里解出股票代码。解不出返回 None。

    优先用 meta.underlying_symbol；没有就从期权合约代码前缀切
    （OCC 格式：代码 + 6 位到期日 + C/P + 8 位行权价 = 后缀恰好 15 位）。
    """
    meta = alert.get("meta") or {}
    underlying = meta.get("underlying_symbol")
    if underlying:
        return str(underlying).upper()

    symbol = alert.get("symbol")
    if not symbol:
        return None
    symbol = str(symbol).upper()
    if len(symbol) > _OCC_TAIL_LEN and symbol[-_OCC_TAIL_LEN:].isalnum():
        head = symbol[:-_OCC_TAIL_LEN]
        if head.isalpha():
            return head
    return symbol if symbol.isalpha() else None


def split_premium(kind: str | None, ask_prem: float,
                  bid_prem: float) -> tuple[float, float]:
    """把一条期权异动的溢价拆成「看多多少、看空多少」。

    白话：在卖价成交说明是买方主动（急着买），在买价成交说明是卖方主动。
    买看涨 = 看多，卖看涨 = 看空；买看跌 = 看空，卖看跌 = 看多。
    """
    if kind == "call":
        return ask_prem, bid_prem
    if kind == "put":
        return bid_prem, ask_prem
    return 0.0, 0.0


def summarize_flow(rows: list[dict] | None) -> dict:
    """把一只票的一堆期权异动汇总成四个数。rows 为空也返回结构完整的零值。"""
    bullish = bearish = biggest = 0.0
    count = 0
    for row in rows or []:
        ask = _to_float(row.get("total_ask_side_prem"))
        bid = _to_float(row.get("total_bid_side_prem"))
        up, down = split_premium(row.get("type"), ask, bid)
        bullish += up
        bearish += down
        biggest = max(biggest, _to_float(row.get("total_premium")))
        count += 1
    return {
        "bullish_premium": round(bullish, 2),
        "bearish_premium": round(bearish, 2),
        "net_premium": round(bullish - bearish, 2),
        "biggest_premium": round(biggest, 2),
        "alert_count": count,
        "source": "uw_live",
    }

# -*- coding: utf-8 -*-
"""日线技术面快照。5 个工具里有 4 个要它。

## 这个模块只管技术面，这是硬边界

短波段只看「价格怎么走 + 钱往哪押 + 有没有雷」，公司好不好一概不看
（设计文档第三节）。所以这里的 SQL **不查任何估值和增长列**——市盈率、
营收增长、利润率、分析师目标价，一个都不碰。想要基本面去调
`core/fundamental.py`，那个模块只被中线档调用。

这不是靠自觉：`tests/test_sql_rules.py` 会扫这个文件的源码，
出现 `BANNED_FUNDAMENTAL_COLUMNS` 里任何一个词就直接红。

## 指标不用自己算

`stock_ohlcv_daily` 里 `ma_20/50/200`、`rsi_14`、`vol_ratio`、`atr_14`、
`atr_pct`、`high_20`、`high_55`、`dist_ma20_pct`、`dist_ma50_pct` 全是
tt-data-hub 预先算好的。自己再算一遍只会算出跟别处不一致的数。

## 两种取数方式，别用错

- `get()`：几只票。按票 `order by date desc limit 8` 走 (ticker, date) 主键
  索引倒扫，实测每票 1.8 千代价，顺带保住停牌退市的票（它们最后一根 K 线
  不是最新交易日，但仍然拿得到）。
- `scan()`：全市场。先单独查出该市场的最新交易日，再等值比较。
  **绝不能**写成 `date = (select max(date) ... where ticker = o.ticker)`
  这种相关子查询，那是并行全表扫 380 万行（实测代价 17.6 万）。
"""
import datetime

from db import pg

#: 短波段禁用的基本面列。这个文件里出现任何一个都是 bug，回归测试会拦。
BANNED_FUNDAMENTAL_COLUMNS = frozenset({
    "pe_ratio", "ps_ratio", "pb_ratio", "peg_ratio", "forward_pe",
    "ev_to_ebitda", "revenue_growth_yoy", "earnings_growth_yoy",
    "gross_margin", "operating_margin", "profit_margin", "roe",
    "fcf_yield", "analyst_rating", "analyst_target_price", "analyst_count",
    "dividend_yield",
})

MARKETS = ("US", "CN")

#: 最新一根 K 线离今天超过这么多个自然日，就算行情陈旧。
#: 3 天能盖住正常的周末（周五收盘到周一早上是 3 天）。
STALE_DAYS = 3

#: 取几根日线。8 根够算：前一日的 20 日高点（判突破）、近 3 日有没有放量阳线
#: （判超跌反弹）、5 天前的 50 日均线（判中线趋势是不是在往上走）。
_BARS = 8

#: 近 3 日的「放量阳线」判据：收盘高于开盘，且量能不低于平时的 1.2 倍。
_VOL_UP_RATIO = 1.2

#: 美股流动性门槛：20 日均额 1000 万美元。实测过线的有 1860 只。
#: A股：5000 万人民币，且排除 ST（设计文档第四节）。
DEFAULT_MIN_DOLLAR_VOLUME = {"US": 10_000_000.0, "CN": 50_000_000.0}

_BAR_COLUMNS = """
    d.date, d.open, d.close, d.pct_chg, d.volume,
    d.ma_20, d.ma_50, d.ma_200, d.rsi_14, d.vol_ratio, d.vol_ma_20,
    d.atr_14, d.atr_pct, d.high_20, d.high_55,
    d.dist_ma20_pct, d.dist_ma50_pct
"""

_LATEST_DAY_SQL = """
select max(date) as day
from stock_ohlcv_daily
where market = %s
  and date >= current_date - 30
"""

# 每只票走一次索引倒扫，取最近 8 根。停牌的票也能拿到它自己最后一根。
# 顺带把公司名带出来——工具层要拿它显示，不然每个工具都得自己再查一次 stocks_meta。
_GET_SQL = f"""
select t.ticker, m.company_name, o.*
from unnest(%s::text[]) as t(ticker)
left join stocks_meta m
       on m.ticker = t.ticker
      and m.market = %s
left join lateral (
    select {_BAR_COLUMNS}
    from stock_ohlcv_daily d
    where d.ticker = t.ticker
      and d.market = %s
    order by d.date desc
    limit {_BARS}
) o on true
order by t.ticker, o.date desc
"""

# 全池扫描。先拿最新交易日（上面那条小查询），再等值比较，实测 109 毫秒。
# 时间窗收到 20 个自然日，够算 5 天前的 50 日均线，又不会扫太多行。
_SCAN_SQL_HEAD = f"""
with recent as (
    select d.ticker,
           {_BAR_COLUMNS},
           lag(d.high_20) over w as prior_high_20,
           lag(d.ma_50, 5) over w as ma_50_prev5,
           max(case when d.close > d.open and d.vol_ratio >= {_VOL_UP_RATIO}
                    then 1 else 0 end)
               over (partition by d.ticker order by d.date
                     rows between 2 preceding and current row) as vol_up_3d,
           row_number() over (partition by d.ticker
                              order by d.date desc) as rn
    from stock_ohlcv_daily d
    where d.market = %s
      and d.date >= %s
    window w as (partition by d.ticker order by d.date)
)
"""

_SCAN_SQL_US = _SCAN_SQL_HEAD + """
select r.*, m.company_name
from recent r
join ticker_over20b u on u.ticker = r.ticker
left join stocks_meta m on m.ticker = r.ticker and m.market = 'US'
where r.rn = 1
  and r.date = %s
  and r.close * r.vol_ma_20 >= %s
"""

_SCAN_SQL_CN = _SCAN_SQL_HEAD + """
select r.*, u.name as company_name
from recent r
join cn_universe u on u.ticker = r.ticker
where r.rn = 1
  and r.date = %s
  and not u.is_st
  and u.avg_amount_20d >= %s
"""


def _check_market(market: str) -> str:
    market = (market or "").upper()
    if market not in MARKETS:
        raise ValueError(f"market 只能是 US 或 CN，收到 {market!r}")
    return market


def _f(value):
    return None if value is None else float(value)


def latest_trading_day(market: str) -> datetime.date | None:
    """该市场最新有日线的那一天。全池扫描前先拿它，别写相关子查询。"""
    row = pg.query_one(_LATEST_DAY_SQL, (_check_market(market),))
    return row["day"] if row else None


def _enrich(bars: list[dict], ticker: str, market: str,
            today: datetime.date) -> dict | None:
    """把一只票最近 8 根日线压成一份快照。bars 已按日期倒序。"""
    if not bars or bars[0].get("date") is None:
        return None

    last = bars[0]
    close = _f(last["close"])
    ma_20, ma_50, ma_200 = _f(last["ma_20"]), _f(last["ma_50"]), _f(last["ma_200"])
    high_20, high_55 = _f(last["high_20"]), _f(last["high_55"])
    vol_ma_20 = _f(last["vol_ma_20"])

    # 前一日的 20 日高点：判「突破」要跟昨天的高点比，跟今天比永远不成立
    prior_high_20 = _f(bars[1]["high_20"]) if len(bars) > 1 else None

    # 50 日均线在不在往上走：跟 5 根之前比
    ma_50_slope_pct = None
    if len(bars) > 5 and ma_50:
        past = _f(bars[5]["ma_50"])
        if past:
            ma_50_slope_pct = round((ma_50 - past) / past * 100, 3)

    # 近 3 日有没有出现过放量阳线
    had_vol_up_3d = any(
        _f(b["close"]) is not None and _f(b["open"]) is not None
        and _f(b["close"]) > _f(b["open"])
        and (_f(b["vol_ratio"]) or 0) >= _VOL_UP_RATIO
        for b in bars[:3])

    # 近 20 日内是不是创过新高：20 日高点就等于 55 日高点，说明这个高点
    # 是最近 20 天内做出来的。省掉一次额外查询。
    made_20d_high_recently = bool(
        high_20 and high_55 and high_20 >= high_55 * 0.999)

    days_since_bar = (today - last["date"]).days

    return {
        "ticker": ticker,
        "market": market,
        "company_name": last.get("company_name"),
        "date": last["date"],
        "close": close,
        "open": _f(last["open"]),
        "pct_chg": _f(last["pct_chg"]),
        "volume": _f(last["volume"]),
        "dollar_volume": round(close * vol_ma_20, 2)
                         if close and vol_ma_20 else None,
        "ma_20": ma_20,
        "ma_50": ma_50,
        "ma_200": ma_200,
        "above_ma20": None if ma_20 is None else close > ma_20,
        "above_ma50": None if ma_50 is None else close > ma_50,
        "above_ma200": None if ma_200 is None else close > ma_200,
        "rsi_14": _f(last["rsi_14"]),
        "vol_ratio": _f(last["vol_ratio"]),
        "atr_14": _f(last["atr_14"]),
        "atr_pct": _f(last["atr_pct"]),
        "high_20": high_20,
        "high_55": high_55,
        "dist_ma20_pct": _f(last["dist_ma20_pct"]),
        "dist_ma50_pct": _f(last["dist_ma50_pct"]),
        "dist_from_20d_high_pct": round((close - high_20) / high_20 * 100, 2)
                                  if close and high_20 else None,
        "prior_high_20": prior_high_20,
        "ma_50_slope_pct": ma_50_slope_pct,
        "had_vol_up_3d": had_vol_up_3d,
        "made_20d_high_recently": made_20d_high_recently,
        "stale": days_since_bar > STALE_DAYS,
        "days_since_bar": days_since_bar,
    }


def get(tickers: list[str], market: str) -> dict[str, dict | None]:
    """取一批票的技术面快照。没有行情的票值是 None，但键一定在。"""
    market = _check_market(market)
    tickers = [t.upper().strip() for t in (tickers or []) if t and t.strip()]
    if not tickers:
        return {}

    rows = pg.query(_GET_SQL, (tickers, market, market))
    today = datetime.date.today()

    grouped: dict[str, list[dict]] = {t: [] for t in tickers}
    for row in rows:
        grouped.setdefault(row["ticker"], []).append(row)

    return {t: _enrich(grouped.get(t, []), t, market, today) for t in tickers}


def scan(market: str, min_dollar_volume: float | None = None) -> list[dict]:
    """全市场扫描，只留过了流动性门槛的票。"""
    market = _check_market(market)
    day = latest_trading_day(market)
    if day is None:
        return []

    threshold = (min_dollar_volume if min_dollar_volume is not None
                 else DEFAULT_MIN_DOLLAR_VOLUME[market])
    window_start = day - datetime.timedelta(days=20)
    sql = _SCAN_SQL_US if market == "US" else _SCAN_SQL_CN

    today = datetime.date.today()
    out = []
    for row in pg.query(sql, (market, window_start, day, threshold)):
        # scan 的窗口函数已经把三个派生值算好了，直接塞进去，
        # 免得 _enrich 因为只拿到一行而把它们判成 None
        snap = _enrich([row], row["ticker"], market, today)
        if snap is None:
            continue
        snap["prior_high_20"] = _f(row.get("prior_high_20"))
        snap["had_vol_up_3d"] = bool(row.get("vol_up_3d"))
        ma_50, prev5 = snap["ma_50"], _f(row.get("ma_50_prev5"))
        snap["ma_50_slope_pct"] = (round((ma_50 - prev5) / prev5 * 100, 3)
                                   if ma_50 and prev5 else None)
        out.append(snap)
    return out

"""形态识别、分档评分、止损目标价。全是纯函数，不碰数据库也不碰网络。

## 为什么单独一个模块

两个原因。一是这些判断是这套东西里最该被测的部分——阈值定得对不对、
缺数据时会不会算歪，都要能离线反复试。二是**短线和中线的分界要在函数签名上
就锁死**：`score_short()` 的入参里根本没有基本面这个位置，
想在短波段里用市盈率会直接 TypeError，而不是悄悄算进去。

## 归一化：缺数据不等于扣分

某一路数据缺了（A股没期权、某票没新闻），把那一项从分母里去掉再算百分比，
并把缺的写进 `gaps`。60 分永远表示「拿到的依据里有六成是好的」。
要是缺一项就白扣 25 分，一只好票会因为「我们没查到它的期权数据」
而被排到烂票后面——那是拿系统的无知去惩罚股票。
"""

# ---- 形态阈值。设计文档第四节，改这里等于改策略，别在调用处硬编码 ----

#: 突破要放量到平时的几倍
BREAKOUT_VOL_RATIO = 1.5
#: 回踩：收盘落在 20 日均线的这个区间里（百分比）
PULLBACK_BAND = (-3.0, 2.0)
#: 回踩：RSI 要在这个不温不火的区间
PULLBACK_RSI = (40.0, 60.0)
#: 超跌反弹：RSI 低于这个数
OVERSOLD_RSI = 35.0
#: 超跌反弹：离 50 日均线至少这么远（负数=在均线下方）
OVERSOLD_DIST_MA50 = -8.0
#: 中线趋势延续：离 52 周高点不超过这么多
MID_NEAR_52W_HIGH = 15.0

#: 止损放在入场价下方几倍 ATR。不同波动性的票用同一个百分比止损没有意义。
STOP_ATR_MULT = 1.5
#: 持仓止损：成本下方几倍 ATR（比新开仓宽，已经有浮盈浮亏的仓位不该被扫）
POSITION_STOP_ATR_MULT = 2.0
#: 目标价按几倍风险距离给
TARGET_R_MULTIPLES = (2.0, 3.0)

SHORT_SETUPS = ("breakout", "pullback", "oversold_bounce")
MID_SETUPS = ("trend_continuation", "bottom_reversal")

SETUP_LABELS = {
    "breakout": "突破",
    "pullback": "回踩均线",
    "oversold_bounce": "超跌反弹",
    "trend_continuation": "趋势延续",
    "bottom_reversal": "底部反转",
}


def _num(value):
    """拿一个数，拿不到就返回 None。快照里到处可能是 None。"""
    try:
        return None if value is None else float(value)
    except (TypeError, ValueError):
        return None

def detect_short_setup(snap: dict) -> str | None:
    """短波段三选一。都不像就返回 None（大多数票都该返回 None）。"""
    close = _num(snap.get("close"))
    ma_20 = _num(snap.get("ma_20"))
    ma_50 = _num(snap.get("ma_50"))
    ma_200 = _num(snap.get("ma_200"))
    rsi = _num(snap.get("rsi_14"))
    vol_ratio = _num(snap.get("vol_ratio"))
    prior_high = _num(snap.get("prior_high_20"))
    dist_ma20 = _num(snap.get("dist_ma20_pct"))
    dist_ma50 = _num(snap.get("dist_ma50_pct"))

    if close is None or ma_20 is None or ma_50 is None:
        return None

    # 突破：收盘越过昨天的 20 日高点 + 放量 + 均线多头排列。
    # 跟「昨天的」高点比是关键——跟今天的比永远不成立，今天的高点包含今天。
    if (prior_high is not None and close > prior_high
            and vol_ratio is not None and vol_ratio >= BREAKOUT_VOL_RATIO
            and close > ma_20 > ma_50):
        return "breakout"

    # 回踩：上升趋势里回到 20 日均线附近喘口气，RSI 不温不火，
    # 而且近 20 日内确实创过新高（不是一路下跌路过均线）
    if (ma_20 > ma_50 and rsi is not None and dist_ma20 is not None
            and PULLBACK_RSI[0] <= rsi <= PULLBACK_RSI[1]
            and PULLBACK_BAND[0] <= dist_ma20 <= PULLBACK_BAND[1]
            and snap.get("made_20d_high_recently")):
        return "pullback"

    # 超跌反弹：长期趋势还在（站上 200 日均线），但短期跌过头了，
    # 而且近 3 日已经出现过放量阳线——有人开始接了，不是空中接飞刀
    if (ma_200 is not None and close > ma_200
            and rsi is not None and rsi < OVERSOLD_RSI
            and dist_ma50 is not None and dist_ma50 < OVERSOLD_DIST_MA50
            and snap.get("had_vol_up_3d")):
        return "oversold_bounce"

    return None


def detect_mid_setup(snap: dict, fund: dict | None) -> str | None:
    """中线两选一。**没有基本面就不给形态**——中线的一半依据在基本面上，
    缺了还硬给一个形态，等于把短线形态贴个中线标签卖出去。"""
    if not fund:
        return None

    close = _num(snap.get("close"))
    ma_50 = _num(snap.get("ma_50"))
    ma_200 = _num(snap.get("ma_200"))
    slope = _num(snap.get("ma_50_slope_pct"))
    if close is None or ma_200 is None:
        return None

    revenue_growth = _num(fund.get("revenue_growth_yoy"))
    profit_margin = _num(fund.get("profit_margin"))
    week_52_high = _num(fund.get("week_52_high"))

    # 趋势延续：多头排列 + 50 日均线在往上 + 离 52 周高点不远 + 生意在赚钱
    if (ma_50 is not None and close > ma_50 > ma_200
            and (slope is None or slope > 0)
            and revenue_growth is not None and revenue_growth > 0
            and profit_margin is not None and profit_margin > 0):
        if week_52_high:
            gap = (week_52_high - close) / week_52_high * 100
            if gap > MID_NEAR_52W_HIGH:
                return None
        return "trend_continuation"

    # 底部反转：刚站上 200 日均线，均线走平或翘头，基本面没在恶化
    if (close > ma_200 and (slope is None or slope >= -0.5)
            and ma_50 is not None and close > ma_50
            and (revenue_growth is None or revenue_growth > -10)):
        return "bottom_reversal"

    return None


# --------------------------------------------------------- 评分


class _Ledger:
    """记分板：每一项记「拿了多少 / 满分多少」，缺的项不进分母。"""

    def __init__(self):
        self.earned = 0.0
        self.possible = 0.0
        self.reasons: list[str] = []
        self.risks: list[str] = []
        self.gaps: list[str] = []

    def add(self, earned: float, possible: float, reason: str | None = None):
        self.earned += earned
        self.possible += possible
        if reason:
            self.reasons.append(reason)

    def skip(self, what: str):
        """这一项没数据。不进分母，写进 gaps。"""
        self.gaps.append(what)

    def risk(self, text: str):
        self.risks.append(text)

    def result(self) -> dict:
        score = round(self.earned / self.possible * 100) if self.possible else 0
        return {
            "score": max(0, min(100, score)),
            "reasons": self.reasons,
            "risks": self.risks,
            "gaps": self.gaps,
        }


def _score_trend(led: _Ledger, snap: dict, weight: float):
    """趋势：站在哪几条均线上方、排列顺不顺。"""
    got = 0.0
    parts = []
    if snap.get("above_ma20"):
        got += 0.34
        parts.append("站上 20 日均线")
    if snap.get("above_ma50"):
        got += 0.33
        parts.append("站上 50 日均线")
    ma_20, ma_50 = _num(snap.get("ma_20")), _num(snap.get("ma_50"))
    if ma_20 and ma_50 and ma_20 > ma_50:
        got += 0.16
        parts.append("均线多头排列")
    if snap.get("above_ma200"):
        got += 0.17
        parts.append("站上 200 日均线")
    led.add(got * weight, weight, "、".join(parts) if parts else None)
    if not parts:
        led.risk("均线全在头顶，趋势是向下的")


def _score_volume(led: _Ledger, snap: dict, weight: float):
    """量能：突破有没有量确认。"""
    ratio = _num(snap.get("vol_ratio"))
    if ratio is None:
        led.skip("量比数据缺失")
        return
    if ratio >= 2.0:
        led.add(weight, weight, f"放量 {ratio:.1f} 倍")
    elif ratio >= BREAKOUT_VOL_RATIO:
        led.add(weight * 0.8, weight, f"放量 {ratio:.1f} 倍")
    elif ratio >= 1.2:
        led.add(weight * 0.5, weight, f"量能温和放大（{ratio:.1f} 倍）")
    elif ratio >= 0.8:
        led.add(weight * 0.25, weight, f"量能平常（{ratio:.1f} 倍）")
    else:
        led.add(0.0, weight)
        led.risk(f"缩量到平时的 {ratio:.1f} 倍，没人跟")


def _score_flow(led: _Ledger, flow: dict | None, weight: float):
    """资金确认：期权市场往哪押。"""
    if not flow or not flow.get("alert_count"):
        led.skip("没有期权异动数据")
        return
    bullish = _num(flow.get("bullish_premium")) or 0.0
    bearish = _num(flow.get("bearish_premium")) or 0.0
    total = bullish + bearish
    if total <= 0:
        led.skip("期权异动金额为零")
        return
    tilt = (bullish - bearish) / total
    if tilt >= 0.6:
        led.add(weight, weight, f"期权资金明显偏多（净 {tilt:.0%}）")
    elif tilt >= 0.3:
        led.add(weight * 0.7, weight, f"期权资金偏多（净 {tilt:.0%}）")
    elif tilt >= 0:
        led.add(weight * 0.4, weight, "期权资金多空大致平衡")
    else:
        led.add(0.0, weight)
        led.risk(f"期权资金偏空（净 {tilt:.0%}）")


def _score_news(led: _Ledger, news: dict | None, weight: float):
    """消息面：有没有雷，有没有催化。"""
    if not news:
        led.add(weight * 0.6, weight, "近期无重大消息")
        return
    label = (news.get("sentiment_label") or "").lower()
    significance = (news.get("significant") or "").lower()
    if label == "negative":
        if significance == "high":
            led.add(0.0, weight)
            led.risk("有重大负面消息")
        else:
            led.add(weight * 0.25, weight)
            led.risk("有负面消息")
    elif label == "positive":
        led.add(weight if significance == "high" else weight * 0.8, weight,
                "有正面消息" + ("（重大）" if significance == "high" else ""))
    else:
        led.add(weight * 0.6, weight, "消息面中性")


def score_short(snap: dict, flow: dict | None = None,
                news: dict | None = None) -> dict:
    """短波段评分：趋势 30 + 量能 25 + 资金确认 25 + 消息面 20。

    **入参里没有基本面，这是故意的。** 短波段不看公司好不好
    （设计文档第三节）。想加市盈率进来会直接 TypeError。
    """
    led = _Ledger()
    _score_trend(led, snap, 30)
    _score_volume(led, snap, 25)
    _score_flow(led, flow, 25)
    _score_news(led, news, 20)
    if snap.get("stale"):
        led.risk(f"行情已经 {snap.get('days_since_bar')} 天没更新")
    return led.result()

        else:
            led.add(5, 25)
            led.risk(f"所属板块「{board.get('board_name')}」偏弱，逆着板块难做")

    # 情绪与消息：涨停家数和炸板率决定今天该不该出手
    if sentiment is None and news is None:
        led.skip("没有市场情绪和消息数据")
    else:
        got = 0.0
        parts = []
        if sentiment:
            limit_up = sentiment.get("limit_up_count") or 0
            broken = _num(sentiment.get("broken_rate"))
            if limit_up >= 60 and (broken is None or broken < 0.3):
                got += 12
                parts.append(f"涨停 {limit_up} 家，情绪偏热")
            elif limit_up >= 30:
                got += 8
                parts.append(f"涨停 {limit_up} 家，情绪一般")
            else:
                parts.append(f"涨停只有 {limit_up} 家，情绪偏冷")
            if broken is not None and broken >= 0.4:
                led.risk(f"炸板率 {broken:.0%}，追涨容易被埋")
        if news:
            label = (news.get("sentiment_label") or "").lower()
            if label == "negative":
                led.risk("有负面消息")
            elif label == "positive":
                got += 8
                parts.append("有正面消息")
            else:
                got += 5
        led.add(got, 20, "、".join(parts) if parts else None)

    if snap.get("stale"):
        led.risk(f"行情已经 {snap.get('days_since_bar')} 天没更新")
    return led.result()


def score_mid(snap: dict, fund: dict | None = None,
              news: dict | None = None) -> dict:
    """中线评分：趋势 25 + 基本面 35 + 相对强度 20 + 消息面 20。

    中线才开始看公司好不好。这个函数**有** fund 参数，短线那两个没有。
    """
    led = _Ledger()
    _score_trend(led, snap, 25)

    if not fund:
        led.skip("没有基本面数据（A股基本面目前只覆盖 150 只票）")
    else:
        got = 0.0
        parts = []
        revenue = _num(fund.get("revenue_growth_yoy"))
        earnings = _num(fund.get("earnings_growth_yoy"))
        margin = _num(fund.get("profit_margin"))
        roe = _num(fund.get("roe"))
        target = _num(fund.get("analyst_target_price"))
        close = _num(snap.get("close"))
        if revenue is not None and revenue > 0:
            got += 10
            parts.append(f"营收同比增长 {revenue:.1f}%")
        elif revenue is not None:
            led.risk(f"营收同比下滑 {abs(revenue):.1f}%")
        if earnings is not None and earnings > 0:
            got += 8
            parts.append(f"利润同比增长 {earnings:.1f}%")
        if margin is not None and margin > 0:
            got += 7
            parts.append(f"净利率 {margin:.1f}%")
        if roe is not None and roe > 10:
            got += 5
            parts.append(f"ROE {roe:.1f}%")
        if target and close and target > close:
            got += 5
            parts.append(f"分析师目标价 {target:.2f}，比现价高 "
                         f"{(target - close) / close * 100:.0f}%")
        led.add(got, 35, "、".join(parts) if parts else None)

    # 相对强度：离 52 周高点多远
    week_52_high = _num((fund or {}).get("week_52_high"))
    close = _num(snap.get("close"))
    if not week_52_high or not close:
        led.skip("没有 52 周高点数据")
    else:
        gap = (week_52_high - close) / week_52_high * 100
        if gap < 5:
            led.add(20, 20, "贴着 52 周高点")
        elif gap < 10:
            led.add(15, 20, f"离 52 周高点 {gap:.0f}%")
        elif gap < MID_NEAR_52W_HIGH:
            led.add(10, 20, f"离 52 周高点 {gap:.0f}%")
        else:
            led.add(5, 20)
            led.risk(f"离 52 周高点还有 {gap:.0f}%，相对强度弱")

    _score_news(led, news, 20)
    if snap.get("stale"):
        led.risk(f"行情已经 {snap.get('days_since_bar')} 天没更新")
    return led.result()

def _entry_zone(snap: dict, setup: str) -> tuple[float, float] | None:
    close = _num(snap.get("close"))
    ma_20 = _num(snap.get("ma_20"))
    ma_200 = _num(snap.get("ma_200"))
    if close is None:
        return None
    if setup == "breakout":
        return close * 0.995, close * 1.02
    if setup == "pullback" and ma_20:
        return ma_20 * 0.98, ma_20 * 1.01
    if setup == "oversold_bounce":
        return close * 0.98, close * 1.02
    if setup == "trend_continuation" and ma_20:
        return min(ma_20 * 0.99, close), close * 1.01
    if setup == "bottom_reversal" and ma_200:
        return min(ma_200 * 0.98, close), close * 1.02
    return close * 0.99, close * 1.01


def plan_trade(snap: dict, setup: str) -> dict:
    """给一个形态算出买入区间、止损、两档目标价。

    止损用 ATR 算，不是拍脑袋定个百分比——一只每天晃 8% 的票和一只每天晃 1%
    的票，用同一个 5% 止损，前者天天被扫，后者根本止不住。
    """
    gaps: list[str] = []
    zone = _entry_zone(snap, setup)
    atr = _num(snap.get("atr_14"))

    if zone is None:
        return {"entry_zone": None, "stop": None, "stop_pct": None,
                "targets": [], "rr_ratio": None, "gaps": ["没有价格数据"]}

    entry = (zone[0] + zone[1]) / 2
    if not atr:
        gaps.append("没有 ATR，算不出止损位")
        return {"entry_zone": [round(zone[0], 2), round(zone[1], 2)],
                "stop": None, "stop_pct": None, "targets": [],
                "rr_ratio": None, "gaps": gaps}

    stop = entry - STOP_ATR_MULT * atr
    risk = entry - stop
    targets = [round(entry + m * risk, 2) for m in TARGET_R_MULTIPLES]
    return {
        "entry_zone": [round(zone[0], 2), round(zone[1], 2)],
        "stop": round(stop, 2),
        "stop_pct": round(risk / entry * 100, 2),
        "targets": targets,
        "rr_ratio": TARGET_R_MULTIPLES[0],
        "gaps": gaps,
    }


def position_stop(avg_cost: float, snap: dict) -> dict:
    """已有仓位的止损位：成本下方 2 倍 ATR 和 20 日均线，取高的那个。

    取高的那个是因为：均线在成本上方时，说明已经有浮盈，该把止损抬上来护住；
    均线在下方时，用成本减 ATR 才不会被日常波动扫掉。
    """
    close = _num(snap.get("close"))
    atr = _num(snap.get("atr_14"))
    ma_20 = _num(snap.get("ma_20"))
    avg_cost = _num(avg_cost)

    candidates = []
    if avg_cost and atr:
        candidates.append(("成本 - 2×ATR", avg_cost - POSITION_STOP_ATR_MULT * atr))
    if ma_20:
        candidates.append(("ma_20", ma_20))
    if not candidates:
        return {"suggested_stop": None, "basis": None, "distance_pct": None,
                "breached": None, "gaps": ["没有 ATR 也没有均线，算不出止损"]}

    basis, stop = max(candidates, key=lambda item: item[1])
    return {
        "suggested_stop": round(stop, 2),
        "basis": basis,
        "distance_pct": round((close - stop) / close * 100, 2) if close else None,
        "breached": bool(close is not None and close < stop),
        "gaps": [],
    }

## 新闻表的两个坑

1. **`news` 没有 ticker 列。** 代码在 `related_tickers` 里，是个 text[]，

## 财报日和市值是短线的合法例外

它俩存在 stock_fundamentals 里，但短波段需要它们避雷和过流动性门槛
（设计文档第三节）。所以 `earnings_for()` **只 select ticker /
next_earnings_date / last_earnings_date / market_cap 这四列**，
不写 `select *`，免得把整行基本面顺手带进短线链路。

## 期权异动有两条路

- `options_flow()` 查库里的 `flow_alerts_archive`。全市场扫描用它，快。
- `options_flow_live()` 调 UW 实时接口，取不到就自动退回库里的数据，
  并把 `source` 标成 `db`。持仓盯盘和个股分析用它——库里的期权数据一天
  只灌两次，拿它盯盘名不副实。
"""
import datetime

from core import uw
from db import pg

#: 重要性从高到低。min_significance='Medium' 的意思是 High + Medium。
SIGNIFICANCE_ORDER = ("High", "Medium", "Low")

#: 内部人交易代码：P = 公开市场买入，S = 卖出。
#: A（授予）、M（期权行权）、F（代扣税）、D（处置）不是主动买卖，是噪音。
#: 实测近 30 天：S 4697 条、M 1981 条、A 1870 条、F 996 条、P 770 条。
_INSIDER_CODES = {"P": "buy", "S": "sell"}

_NEWS_SQL = """
select id, title, title_cn, url, published_at, source,
       sentiment_label, sentiment_score, significant, related_tickers
from news
where related_tickers && %s::text[]
  and published_at >= now() - make_interval(days => %s)
  and significant = any(%s)
order by published_at desc
limit %s
"""

_NEWS_RECENT_SQL = """
select id, title, title_cn, url, published_at, source,
       sentiment_label, sentiment_score, significant, related_tickers
from news
where published_at >= now() - make_interval(hours => %s)
  and significant = any(%s)
  and (%s::text[] is null or related_tickers && %s::text[])
order by published_at desc
limit %s
"""

# 只取这四列。别改成 select *，见模块注释。
_EARNINGS_SQL = """
select distinct on (ticker)
       ticker, next_earnings_date, last_earnings_date, market_cap
from stock_fundamentals
where ticker = any(%s)
  and market = %s
order by ticker, updated_at desc
"""

_FLOW_SQL = """
select ticker,
       count(*) as alert_count,
       sum(case when opt_type = 'call' then ask_prem else bid_prem end)
           as bullish_premium,
       sum(case when opt_type = 'call' then bid_prem else ask_prem end)
           as bearish_premium,
       max(total_premium) as biggest_premium,
       max(day) as last_day
from flow_alerts_archive
where ticker = any(%s)
  and day >= %s
group by ticker
"""

_INSIDER_SQL = """
select ticker,
       payload->>'transaction_code' as code,
       count(*) as n,
       sum((payload->>'amount')::numeric) as amount
from uw_insider_tx
where ticker = any(%s)
  and filing_date >= %s
  and payload->>'transaction_code' = any(%s)
group by ticker, payload->>'transaction_code'
"""

# 国会议员申报的交易。金额是个区间字符串（"$50,001 - $100,000"），
# 原样带出来——把它折算成一个数会假装精确。
_CONGRESS_SQL = """
select ticker, transaction_date, filed_at_date,
       payload->>'name' as member,
       payload->>'member_type' as member_type,
       payload->>'txn_type' as txn_type,
       payload->>'amounts' as amounts
from uw_congress
where ticker = any(%s)
  and transaction_date >= %s
order by transaction_date desc
limit 40
"""

_GEX_SQL = """
select distinct on (ticker)
       ticker, snapshot_date, call_wall, put_wall, gamma_flip, gamma_magnet
from uw_gex_daily
where ticker = any(%s)
order by ticker, snapshot_date desc
"""


def _clean(tickers) -> list[str]:
    return [t.upper().strip() for t in (tickers or []) if t and t.strip()]


def _levels(min_significance: str) -> list[str]:
    """'Medium' -> ['High', 'Medium']。认不出的当 Medium。"""
    try:
        cut = SIGNIFICANCE_ORDER.index(min_significance)
    except ValueError:
        cut = 1
    return list(SIGNIFICANCE_ORDER[:cut + 1])


def _shape_news(row: dict) -> dict:
    return {
        "title": row.get("title_cn") or row.get("title"),
        "title_en": row.get("title"),
        "url": row.get("url"),
        "published_at": row.get("published_at"),
        "source": row.get("source"),
        "sentiment_label": row.get("sentiment_label"),
        "sentiment_score": row.get("sentiment_score"),
        "significant": row.get("significant"),
        "tickers": row.get("related_tickers") or [],
    }


def news_for(tickers: list[str], days: int = 7,
             min_significance: str = "Medium",
             per_ticker: int = 3) -> dict[str, list[dict]]:
    """按票分组的近期新闻，每票最多 per_ticker 条。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}

    # 一次查回来再在 Python 里分组。一条新闻可能同时关联几只票，
    # 按票分别查会把同一条新闻查很多遍。
    rows = pg.query(_NEWS_SQL, (tickers, days, _levels(min_significance),
                                per_ticker * len(tickers) * 4))
    out: dict[str, list[dict]] = {t: [] for t in tickers}
    wanted = set(tickers)
    for row in rows:
        item = _shape_news(row)
        for ticker in wanted & set(item["tickers"]):
            if len(out[ticker]) < per_ticker:
                out[ticker].append(item)
    return out


def news_recent(tickers: list[str] | None = None, hours: int = 24,
                min_significance: str = "Medium",
                limit: int = 60) -> list[dict]:
    """最近 N 小时的新闻，按时间倒序。tickers 为 None 就是全市场。"""
    tickers = _clean(tickers) if tickers else None
    rows = pg.query(_NEWS_RECENT_SQL,
                    (hours, _levels(min_significance), tickers, tickers, limit))
    return [_shape_news(row) for row in rows]


def earnings_for(tickers: list[str], market: str) -> dict[str, dict | None]:
    """下次财报日还有几天。没有数据的票值是 None。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}

    today = datetime.date.today()
    found = {}
    for row in pg.query(_EARNINGS_SQL, (tickers, market.upper())):
        next_date = row.get("next_earnings_date")
        days_until = None
        if isinstance(next_date, datetime.date):
            days_until = (next_date - today).days
        found[row["ticker"]] = {
            "next_earnings_date": next_date,
            "last_earnings_date": row.get("last_earnings_date"),
            "days_until": days_until,
            "market_cap": row.get("market_cap"),
        }
    return {t: found.get(t) for t in tickers}


def options_flow(tickers: list[str], days: int = 5) -> dict[str, dict]:
    """库里的期权异动汇总。没记录的票返回零值，不返回 None。

    看多看空怎么分：在卖价成交说明买方主动，在买价成交说明卖方主动。
    买看涨=看多、卖看涨=看空、买看跌=看空、卖看跌=看多。
    """
    tickers = _clean(tickers)
    if not tickers:
        return {}

    since = datetime.date.today() - datetime.timedelta(days=days)
    found = {}
    for row in pg.query(_FLOW_SQL, (tickers, since)):
        bullish = float(row.get("bullish_premium") or 0)
        bearish = float(row.get("bearish_premium") or 0)
        found[row["ticker"]] = {
            "bullish_premium": round(bullish, 2),
            "bearish_premium": round(bearish, 2),
            "net_premium": round(bullish - bearish, 2),
            "biggest_premium": float(row.get("biggest_premium") or 0),
            "alert_count": int(row.get("alert_count") or 0),
            "last_day": row.get("last_day"),
            "source": "db",
        }
    empty = {"bullish_premium": 0.0, "bearish_premium": 0.0,
             "net_premium": 0.0, "biggest_premium": 0.0,
             "alert_count": 0, "last_day": None, "source": "db"}
    return {t: found.get(t, dict(empty)) for t in tickers}


def options_flow_live(tickers: list[str]) -> dict[str, dict]:
    """实时期权异动。取不到就退回库里的数据，并把 source 标成 db。

    库里一天只灌两次，做盯盘要实时的；但实时接口 3.6 秒一只票，
    而且会超时，所以永远要有退路。
    """
    tickers = _clean(tickers)
    if not tickers:
        return {}

    fallback = options_flow(tickers)
    if not uw.available():
        return fallback

    live = uw.flow_alerts_many(tickers)
    out = {}
    for ticker in tickers:
        rows = live.get(ticker)
        out[ticker] = uw.summarize_flow(rows) if rows else fallback[ticker]
    return out


def insider_for(tickers: list[str], days: int = 90) -> dict[str, dict]:
    """内部人在公开市场的买卖。授予、行权、代扣税不算，见模块注释。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}

    since = datetime.date.today() - datetime.timedelta(days=days)
    out = {t: {"buy_count": 0, "sell_count": 0,
               "buy_amount": 0.0, "sell_amount": 0.0, "net_amount": 0.0}
           for t in tickers}
    for row in pg.query(_INSIDER_SQL, (tickers, since, list(_INSIDER_CODES))):
        entry = out.get(row["ticker"])
        if entry is None:
            continue
        side = _INSIDER_CODES[row["code"]]
        amount = float(row.get("amount") or 0)
        entry[f"{side}_count"] = int(row["n"])
        entry[f"{side}_amount"] = round(amount, 2)
    for entry in out.values():
        entry["net_amount"] = round(entry["buy_amount"] - entry["sell_amount"], 2)
    return out


def congress_for(tickers: list[str],
                 days: int = 180) -> dict[str, list[dict]]:
    """国会议员申报的这几只票的交易。申报有滞后，所以窗口默认放到半年。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}
    since = datetime.date.today() - datetime.timedelta(days=days)
    out: dict[str, list[dict]] = {t: [] for t in tickers}
    for row in pg.query(_CONGRESS_SQL, (tickers, since)):
        out.setdefault(row["ticker"], []).append({
            "transaction_date": row["transaction_date"],
            "filed_at_date": row.get("filed_at_date"),
            "member": row.get("member"),
            "member_type": row.get("member_type"),
            "txn_type": row.get("txn_type"),
            "amounts": row.get("amounts"),
        })
    return out


def gamma_walls(tickers: list[str]) -> dict[str, dict | None]:
    """期权 gamma 墙（短期的压力位和支撑位）。

    `uw_gex_daily` 实测只覆盖 41 只大盘股，绝大多数票会是 None。
    这是加分项，缺了不致命，但要明写缺失，不能编。
    """
    tickers = _clean(tickers)
    if not tickers:
        return {}
    found = {row["ticker"]: {
        "snapshot_date": row["snapshot_date"],
        "call_wall": row.get("call_wall"),
        "put_wall": row.get("put_wall"),
        "gamma_flip": row.get("gamma_flip"),
        "gamma_magnet": row.get("gamma_magnet"),
    } for row in pg.query(_GEX_SQL, (tickers,))}
    return {t: found.get(t) for t in tickers}
```

"""市场环境和数据新鲜度。

## 美股和 A股不是同一套算法，因为数据不一样

美股有现成的 `market_breadth_daily`，但**它是标普 500 口径**——实测
advances 223 + declines 273 ≈ 500，不是全市场 2000 多只。返回里要写明这一点，

A股没有这张表，当场从日线算：一天 1500 行，几十毫秒。顺带把涨停家数、

## 新鲜度检测

设计文档第八节第三条：最新交易日距今超过 3 天要加陈旧警告，并附上
`ingest_runlog` 里最后几次采集的状态。用户能立刻知道是「今天没行情」
还是「采集挂了」。

_US_BREADTH_SQL = """

       advances, declines, ad_ratio, new_highs_20, new_lows_20,
       breadth_score, breadth_level
from market_breadth_daily
order by date desc
limit 1

_CN_BREADTH_SQL = """

       count(*) filter (where pct_chg > 0) as advances,
       count(*) filter (where pct_chg < 0) as declines,
       round(100.0 * count(*) filter (where close > ma_20)
             / nullif(count(*) filter (where ma_20 is not null), 0), 2)
           as pct_above_ma20,
       round(100.0 * count(*) filter (where close > ma_50)
             / nullif(count(*) filter (where ma_50 is not null), 0), 2)
           as pct_above_ma50,
       round(100.0 * count(*) filter (where close > ma_200)
             / nullif(count(*) filter (where ma_200 is not null), 0), 2)
           as pct_above_ma200,
       count(*) filter (where high_20 is not null
                          and close >= high_20) as new_highs_20
from stock_ohlcv_daily
where market = 'CN'
  and date = %s
"""

_CN_LIMIT_SQL = """

       count(*) as limit_up_count,
       count(*) filter (where open_times > 0) as broken_count,
       max(limit_streak) as max_streak
from cn_limit_pool_daily
where snapshot_date = (select max(snapshot_date) from cn_limit_pool_daily)
"""

_RUNLOG_SQL = """
select job, market, status, rows_written, finished_at
from ingest_runlog
where started_at >= now() - interval '48 hours'
order by started_at desc
limit 12
"""


def _level(ad_ratio, pct_above_ma50) -> str:
    """把两个数翻成一句人话：现在是能出手的环境，还是该收手。"""
    if ad_ratio is None or pct_above_ma50 is None:
        return "UNKNOWN"
    if ad_ratio >= 1.5 and pct_above_ma50 >= 60:
        return "BULLISH"
    if ad_ratio <= 0.6 or pct_above_ma50 <= 30:

def get(market: str) -> dict:

def freshness(market: str) -> dict:
    """行情新不新鲜，采集有没有出事。陈旧时工具要在返回里加警告。"""
    day = snapshot.latest_trading_day(market)
    days_old = (datetime.date.today() - day).days if day else None
    jobs = [dict(row) for row in pg.query(_RUNLOG_SQL)]
    failed = [j for j in jobs if j["status"] in ("failed", "partial")]
    return {
        "market": market.upper(),
        "latest_trading_day": day,
        "days_since": days_old,
        "stale": bool(days_old is not None and days_old > snapshot.STALE_DAYS),
        "recent_jobs": jobs,
        "failed_jobs": [f"{j['job']}({j['status']})" for j in failed],
    }

# -*- coding: utf-8 -*-
"""A股独立信号：主力资金、龙虎榜、板块排名、涨停情绪。

## A股不是「美股那套的残缺版」

A股个股没有期权，所以美股那个「期权异动确认突破真假」的信号在这里不存在。
但 A股有美股没有的东西：主力资金明细（谁在买）、龙虎榜（游资进出）、
强烈的板块轮动、涨停家数和炸板率（市场情绪温度）。

对应关系：**主力资金净流入在 A股扮演美股的期权异动**——都是回答
「这个突破背后有没有钱」。

## 金额单位统一是元

采集端已经把两种口径拉平了：个股资金流原本是「1.04亿」这种字符串，
板块资金流原本是以亿元为单位的裸数字，现在库里两张表存的都是**元**。
下游不要再乘除一次（那会造成 1 亿倍的误差，而且不报错）。

## 已知缺口：没有个股 → 行业的映射

`cn_universe.industry` 和 `stocks_meta.industry` 对 A股全是 NULL（实测）。
唯一带行业名的是 `cn_limit_pool_daily.industry`，只覆盖当日涨停的票，
且只有 48/82 能对上板块名。

所以 `board_of()` 只对涨停过的票能给出板块，其余返回 None，调用方要把
`BOARD_MAPPING_GAP` 写进 data_gaps。不静默降级——一个看起来算过板块、
实际没算的评分，比明说「这里缺数据」危险得多。

补上这个映射要在 tt-data-hub 做（把行业成分表灌进 cn_universe.industry），
不在本仓库。
"""
from db import pg

BOARD_TYPES = ("industry", "concept")

#: 缺个股→行业映射时写进 data_gaps 的那句话。见模块注释。
BOARD_MAPPING_GAP = ("A股缺个股所属行业的映射（cn_universe.industry 是空的），"
                     "板块强度只能给全市场排名，给不了这只票所在的板块")

_FUND_FLOW_SQL = """
select ticker, name, snapshot_date, close, pct_chg, turnover_pct,
       inflow, outflow, net_amount, amount,
       net_5d, pct_chg_5d, turnover_5d
from cn_fund_flow_daily
where ticker = any(%s)
  and snapshot_date = (select max(snapshot_date) from cn_fund_flow_daily)
"""

_LHB_SQL = """
select ticker, name, list_date, reason, interpretation,
       close, pct_chg, net_buy, buy_amount, sell_amount,
       net_buy_pct, turnover_pct, ret_1d, ret_5d
from cn_lhb_daily
where ticker = any(%s)
  and list_date >= current_date - %s
order by list_date desc
"""

_BOARD_SQL = """
select board_name, board_index, pct_chg, net_amount, inflow, outflow,
       company_count, leader_name, leader_pct_chg, snapshot_date
from cn_board_flow_daily
where board_type = %s
  and snapshot_date = (select max(snapshot_date) from cn_board_flow_daily
                       where board_type = %s)
order by net_amount desc
"""

# 只有涨停板那张表带行业名。这是目前唯一的个股→行业线索，覆盖面很小。
_BOARD_OF_SQL = """
select l.ticker, l.industry, b.net_amount, b.pct_chg, b.company_count
from cn_limit_pool_daily l
left join cn_board_flow_daily b
       on b.board_name = l.industry
      and b.board_type = 'industry'
      and b.snapshot_date = l.snapshot_date
where l.ticker = any(%s)
  and l.snapshot_date = (select max(snapshot_date) from cn_limit_pool_daily)
"""

_LIMIT_SQL = """
select max(snapshot_date) as date,
       count(*) as limit_up_count,
       count(*) filter (where open_times > 0) as broken_count,
       max(limit_streak) as max_streak
from cn_limit_pool_daily
where snapshot_date = (select max(snapshot_date) from cn_limit_pool_daily)
"""


def _clean(tickers) -> list[str]:
    return [t.upper().strip() for t in (tickers or []) if t and t.strip()]


def _f(value):
    return None if value is None else float(value)


def fund_flow(tickers: list[str]) -> dict[str, dict | None]:
    """主力资金：当日净流入 + 5 日净流入。金额单位是元。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}
    found = {}
    for row in pg.query(_FUND_FLOW_SQL, (tickers,)):
        found[row["ticker"]] = {
            "snapshot_date": row["snapshot_date"],
            "name": row.get("name"),
            "net_amount": _f(row.get("net_amount")),
            "net_5d": _f(row.get("net_5d")),
            "inflow": _f(row.get("inflow")),
            "outflow": _f(row.get("outflow")),
            "amount": _f(row.get("amount")),
            "pct_chg": _f(row.get("pct_chg")),
            "pct_chg_5d": _f(row.get("pct_chg_5d")),
            "turnover_pct": _f(row.get("turnover_pct")),
        }
    return {t: found.get(t) for t in tickers}


def lhb(tickers: list[str], days: int = 30) -> dict[str, list[dict]]:
    """龙虎榜记录。同一天同一只票可能有多条（多个上榜原因）。"""
    tickers = _clean(tickers)
    if not tickers:
        return {}
    out: dict[str, list[dict]] = {t: [] for t in tickers}
    for row in pg.query(_LHB_SQL, (tickers, days)):
        out.setdefault(row["ticker"], []).append({
            "list_date": row["list_date"],
            "reason": row.get("reason"),
            "interpretation": row.get("interpretation"),
            "net_buy": _f(row.get("net_buy")),
            "net_buy_pct": _f(row.get("net_buy_pct")),
            "pct_chg": _f(row.get("pct_chg")),
            "ret_1d": _f(row.get("ret_1d")),
            "ret_5d": _f(row.get("ret_5d")),
        })
    return out


def board_ranking(board_type: str = "industry", top: int = 10) -> dict:
    """板块资金排名。A股是板块市，个股再好逆着板块也难做。"""
    board_type = (board_type or "").lower()
    if board_type not in BOARD_TYPES:
        raise ValueError(f"board_type 只能是 industry 或 concept，"
                         f"收到 {board_type!r}")
    rows = pg.query(_BOARD_SQL, (board_type, board_type))
    shaped = [{
        "board_name": r["board_name"],
        "net_amount": _f(r.get("net_amount")),
        "pct_chg": _f(r.get("pct_chg")),
        "company_count": r.get("company_count"),
        "leader_name": r.get("leader_name"),
        "leader_pct_chg": _f(r.get("leader_pct_chg")),
        "rank": i + 1,
    } for i, r in enumerate(rows)]
    return {
        "board_type": board_type,
        "date": rows[0]["snapshot_date"] if rows else None,
        "total_boards": len(shaped),
        "top": shaped[:top],
        "bottom": shaped[-top:][::-1],
        # 全量排名表。board_of() 要用它把行业名换成名次，
        # 只给首尾各 10 个的话大多数板块查不到名次。
        "all_ranks": {b["board_name"]: b["rank"] for b in shaped},
    }


def board_of(tickers: list[str]) -> dict[str, dict | None]:
    """这几只票各属于哪个行业板块、那个板块今天强不强。

    **大多数票会是 None**，因为库里没有个股→行业的映射，只有当日涨停的票
    带行业名。见模块注释和 BOARD_MAPPING_GAP。
    """
    tickers = _clean(tickers)
    if not tickers:
        return {}

    ranking = board_ranking("industry")
    rank_by_name = ranking["all_ranks"]

    found = {}
    for row in pg.query(_BOARD_OF_SQL, (tickers,)):
        name = row.get("industry")
        if not name:
            continue
        found[row["ticker"]] = {
            "board_name": name,
            "net_amount": _f(row.get("net_amount")),
            "pct_chg": _f(row.get("pct_chg")),
            "company_count": row.get("company_count"),
            "rank": rank_by_name.get(name),
            "total_boards": ranking["total_boards"],
        }
    return {t: found.get(t) for t in tickers}


def limit_sentiment() -> dict:
    """涨停家数、炸板率、最高连板。A股的市场情绪温度计。"""
    row = pg.query_one(_LIMIT_SQL) or {}
    limit_up = row.get("limit_up_count") or 0
    broken = row.get("broken_count") or 0
    return {
        "date": row.get("date"),
        "limit_up_count": limit_up,
        "broken_count": broken,
        "broken_rate": round(broken / limit_up, 3) if limit_up else None,
        "max_streak": row.get("max_streak"),
    }
```

# -*- coding: utf-8 -*-
"""工具 1：持仓分析——我手上这几只票现在什么情况，该不该动。

## 排序按紧急度，不按盈亏

按盈亏排序的话，最该处理的票（刚跌破止损、后天财报）可能排在第五位，
而排第一的只是「涨得最多」——那个不需要你做任何事。这个工具的价值在于
**把需要动手的排在最前面**。

## 汇总按币种分开

用户同时做美股和 A股。把美元市值和人民币市值加起来得到的数字没有任何意义，
所以 summary 是 `{"USD": {...}, "CNY": {...}}`，没有 total 这个键。

## 期权流走实时

只有几只持仓，实时接口 3.6 秒一只、并发跑完 4 秒左右，值得。
库里的期权数据一天只灌两次，拿它看持仓等于看昨天。取不到就自动退回库里的，
并在结果里标明这一路是缓存数据（`flow.source == "db"`）。
"""
import json

from core import catalyst, cn_signals, regime, scoring, snapshot
from db import pg

#: 紧急度分档。数字本身不重要，重要的是顺序：
#: 跌破止损 > 财报临近 > 重大负面消息 > 期权大幅看空 > 正常。
URGENCY = {
    "stop_breached": 90,
    "earnings_soon": 70,
    "bad_news": 65,
    "bearish_flow": 55,
    "cn_outflow": 55,
    "normal": 20,
}

#: 财报还有几天算「临近」。3 个交易日，用 5 个自然日近似（跨周末）。
EARNINGS_SOON_DAYS = 5

#: 期权净溢价偏空到这个金额（美元）才值得报，再小就是噪音。
BEARISH_FLOW_THRESHOLD = 500_000

#: A股主力 5 日净流出到这个金额（元）才值得报。
CN_OUTFLOW_THRESHOLD = 100_000_000

_POSITIONS_SQL = """
select p.ticker, p.market,
       coalesce(p.currency,
                case p.market when 'CN' then 'CNY' else 'USD' end) as currency,
       p.avg_cost, p.shares, p.updated_at,
       m.company_name
from user_positions p
left join stocks_meta m
       on m.ticker = p.ticker
      and m.market = p.market
order by p.ticker
"""


def _num(value):
    return None if value is None else float(value)


def _flags_and_urgency(stop: dict, earnings: dict | None,
                       news: list[dict], flow: dict | None,
                       cn_flow: dict | None,
                       lhb_rows: list[dict]) -> tuple[list[str], int]:
    """把一堆数字翻成「要不要动手」。返回人话标签和紧急度。"""
    flags, urgency = [], URGENCY["normal"]

    if stop.get("breached"):
        flags.append("跌破止损")
        urgency = max(urgency, URGENCY["stop_breached"])

    days_until = (earnings or {}).get("days_until")
    if days_until is not None and 0 <= days_until <= EARNINGS_SOON_DAYS:
        flags.append(f"{days_until} 天后财报")
        urgency = max(urgency, URGENCY["earnings_soon"])

    bad = [n for n in news
           if (n.get("sentiment_label") or "").lower() == "negative"
           and n.get("significant") == "High"]
    if bad:
        flags.append("有重大负面消息")
        urgency = max(urgency, URGENCY["bad_news"])

    if flow and flow.get("net_premium", 0) < -BEARISH_FLOW_THRESHOLD:
        flags.append("期权资金大幅看空")
        urgency = max(urgency, URGENCY["bearish_flow"])

    if cn_flow:
        net_5d = cn_flow.get("net_5d") or 0
        if net_5d < -CN_OUTFLOW_THRESHOLD:
            flags.append(f"主力 5 日净流出 {abs(net_5d) / 1e8:.1f} 亿")
            urgency = max(urgency, URGENCY["cn_outflow"])

    if lhb_rows:
        flags.append(f"近期上过龙虎榜（{len(lhb_rows)} 次）")

    return flags, urgency


def _one(row: dict, snap: dict | None, stop: dict, earnings: dict | None,
         news: list[dict], flow: dict | None, cn_flow: dict | None,
         lhb_rows: list[dict]) -> dict:
    shares = _num(row["shares"]) or 0.0
    avg_cost = _num(row["avg_cost"]) or 0.0
    price = (snap or {}).get("close")

    gaps = []
    if snap is None:
        gaps.append("没有行情数据")
    elif snap.get("stale"):
        gaps.append(f"行情已经 {snap['days_since_bar']} 天没更新")
    if earnings is None:
        gaps.append("没有财报日数据")
    if row["market"] == "US" and (flow is None or flow.get("alert_count") == 0):
        gaps.append("没有期权异动数据")
    if flow and flow.get("source") == "db":
        gaps.append("期权数据取自数据库（实时接口没取到），一天只更新两次")
    if row["market"] == "CN" and cn_flow is None:
        gaps.append("没有主力资金数据")

    flags, urgency = _flags_and_urgency(stop, earnings, news, flow,
                                        cn_flow, lhb_rows)

    return {
        "ticker": row["ticker"],
        "market": row["market"],
        "currency": row["currency"],
        "company_name": row.get("company_name"),
        "shares": shares,
        "avg_cost": avg_cost,
        "price": price,
        "market_value": round(price * shares, 2) if price else None,
        "pnl_pct": round((price - avg_cost) / avg_cost * 100, 2)
                   if price and avg_cost else None,
        "pnl_amount": round((price - avg_cost) * shares, 2)
                      if price and avg_cost else None,
        "trend": {
            "above_ma20": (snap or {}).get("above_ma20"),
            "above_ma50": (snap or {}).get("above_ma50"),
            "above_ma200": (snap or {}).get("above_ma200"),
            "rsi": (snap or {}).get("rsi_14"),
            "vol_ratio": (snap or {}).get("vol_ratio"),
            "atr_pct": (snap or {}).get("atr_pct"),
            "dist_from_20d_high_pct": (snap or {}).get("dist_from_20d_high_pct"),
        },
        "stop": stop,
        "earnings": earnings or {},
        "news": news,
        "flow": flow if row["market"] == "US" else {
            "main_net_today": (cn_flow or {}).get("net_amount"),
            "main_net_5d": (cn_flow or {}).get("net_5d"),
            "lhb_hits": len(lhb_rows),
        },
        "flags": flags,
        "urgency": urgency,
        "data_gaps": gaps,
    }


def _summarize(positions: list[dict]) -> dict:
    """按币种汇总。**没有 total**——见模块注释。"""
    buckets: dict[str, dict] = {}
    for pos in positions:
        currency = pos["currency"]
        block = buckets.setdefault(currency, {
            "market_value": 0.0, "cost_basis": 0.0, "pnl_amount": 0.0,
            "pnl_pct": None, "count": 0, "largest_position_pct": None,
            "largest_position": None,
        })
        block["count"] += 1
        if pos["market_value"]:
            block["market_value"] += pos["market_value"]
        block["cost_basis"] += pos["avg_cost"] * pos["shares"]
        if pos["pnl_amount"]:
            block["pnl_amount"] += pos["pnl_amount"]

    for currency, block in buckets.items():
        cost = block["cost_basis"]
        block["market_value"] = round(block["market_value"], 2)
        block["cost_basis"] = round(cost, 2)
        block["pnl_amount"] = round(block["pnl_amount"], 2)
        block["pnl_pct"] = round(block["pnl_amount"] / cost * 100, 2) if cost else None
        same = [p for p in positions
                if p["currency"] == currency and p["market_value"]]
        if same and block["market_value"]:
            biggest = max(same, key=lambda p: p["market_value"])
            block["largest_position"] = biggest["ticker"]
            block["largest_position_pct"] = round(
                biggest["market_value"] / block["market_value"] * 100, 2)
    return buckets


def review_positions(ticker: str | None = None) -> str:
    """我手上这几只票现在什么情况，该不该动。

    给每只持仓算：现在赚多少赔多少、技术面站在哪、止损该放哪、有没有跌破、
    几天后财报、近期有没有重大消息、期权市场在往哪押（A股换成主力资金和
    龙虎榜）。然后**按需要动手的紧急程度排序**——跌破止损的排最前面，
    只是涨得多的排后面。

    组合汇总按币种分开算，美元和人民币不会加在一起。

    ticker: 只看某一只票时填，一般不填，默认看全部持仓
    """
    try:
        rows = pg.query(_POSITIONS_SQL)
        if ticker:
            wanted = ticker.upper().strip()
            rows = [r for r in rows if r["ticker"] == wanted]
        if not rows:
            return json.dumps({"as_of": None, "positions": [], "summary": {},
                               "warnings": [], "data_gaps": [],
                               "message": "没有持仓" if not ticker
                                          else f"持仓里没有 {ticker}"},
                              ensure_ascii=False, indent=2, default=str)

        by_market: dict[str, list[str]] = {}
        for row in rows:
            by_market.setdefault(row["market"], []).append(row["ticker"])

        snaps, earnings, news, flows = {}, {}, {}, {}
        cn_flows, lhbs = {}, {}
        warnings = []

        for market, tickers in by_market.items():
            snaps.update(snapshot.get(tickers, market))
            earnings.update(catalyst.earnings_for(tickers, market))
            news.update(catalyst.news_for(tickers, days=7,
                                          min_significance="Medium",
                                          per_ticker=3))
            if market == "US":
                flows.update(catalyst.options_flow_live(tickers))
            else:
                cn_flows.update(cn_signals.fund_flow(tickers))
                lhbs.update(cn_signals.lhb(tickers, days=30))

            fresh = regime.freshness(market)
            if fresh["stale"]:
                warnings.append(
                    f"{market} 行情最新只到 {fresh['latest_trading_day']}，"
                    f"距今 {fresh['days_since']} 天。"
                    f"最近失败的采集任务：{fresh['failed_jobs'] or '无'}")

        positions = []
        for row in rows:
            code = row["ticker"]
            snap = snaps.get(code)
            stop = (scoring.position_stop(_num(row["avg_cost"]), snap)
                    if snap else {"suggested_stop": None, "basis": None,
                                  "distance_pct": None, "breached": None,
                                  "gaps": ["没有行情，算不出止损"]})
            positions.append(_one(
                row, snap, stop, earnings.get(code), news.get(code, []),
                flows.get(code), cn_flows.get(code), lhbs.get(code, [])))

        positions.sort(key=lambda p: (-p["urgency"], p["ticker"]))
        as_of = max((s["date"] for s in snaps.values() if s), default=None)

        return json.dumps({
            "as_of": as_of,
            "positions": positions,
            "summary": _summarize(positions),
            "warnings": warnings,
            "data_gaps": sorted({g for p in positions for g in p["data_gaps"]}),
        }, ensure_ascii=False, indent=2, default=str)

    except Exception as exc:
        return json.dumps({"error": str(exc)}, ensure_ascii=False)

# -*- coding: utf-8 -*-
"""工具 2：波段扫描——盘后找值得做的波段机会。

## 为什么只有盘后，没有盘前

日线和期权异动都是收盘后才灌全的，盘前跑等于拿昨天的数据算今天的结论。
而且持有周期是 3 天到 2 个月，按周算，不需要抢开盘那几分钟。

用法：每天盘后跑 `scope="pool"`（持仓 + 自选，几百只）；
周一和周四盘后跑 `scope="full"`（全市场 2000 多只）。

## 为什么全市场扫描走数据库不走实时接口

2082 只美股要算均线、RSI、ATR、20 日新高。这些指标库里已经预先算好了，
一次查询 0.1 秒。走 UW 实时接口要调 2082 次日线，并发 20 路也要 15 分钟——
在对话里等不到结果，而且 UW 的日线只给原始 OHLC 不给指标，等于要在 Python 里
把整套指标重写一遍。

筛完剩十几只之后，`scope="pool"` 会对最终入选的几只补一次实时期权流。

## 财报排雷的两档不一样

短波段：财报 3 个交易日内的**直接剔除**。波段是赌趋势延续，财报是掷骰子，
两件事不该混在一笔交易里。
中线：**保留但标注**。持有两个月本来就会跨过财报，而且财报可能正是催化剂。
"""
import json

from core import (catalyst, cn_signals, fundamental, regime, scoring,
                  snapshot)
from db import pg

HORIZONS = ("short", "mid", "both")
SCOPES = ("pool", "full")

#: 一次最多返回多少只。再多 Claude 也讲不完，用户也看不过来。
MAX_LIMIT = 30

#: 短波段排雷：财报在这么多天内的直接剔除（3 个交易日 ≈ 5 个自然日）。
EARNINGS_BLACKOUT_DAYS = 3

#: pool 范围里，最终给几只补实时期权流。全市场扫描不补（太慢）。
LIVE_FLOW_TOP_N = 15

_POOL_SQL = """
select ticker from user_positions where market = %s
union
select w.ticker
from user_watchlist w
left join stocks_meta m on m.ticker = w.ticker
where coalesce(m.market, 'US') = %s
"""


def _pool_tickers(market: str) -> list[str]:
    return [row["ticker"] for row in pg.query(_POOL_SQL, (market, market))]


def _passes_liquidity(snap: dict, market: str) -> bool:
    """pool 范围也要过流动性门槛——自选里可能躺着一只没人交易的票。"""
    floor = snapshot.DEFAULT_MIN_DOLLAR_VOLUME[market]
    return bool(snap.get("dollar_volume") and snap["dollar_volume"] >= floor)


def _candidates(snaps: list[dict], horizon: str,
                funds: dict) -> list[tuple[dict, str, str]]:
    """挑出命中形态的票。返回 (快照, 形态, 档位)。"""
    out = []
    for snap in snaps:
        if horizon in ("short", "both"):
            setup = scoring.detect_short_setup(snap)
            if setup:
                out.append((snap, setup, "short"))
                continue
        if horizon in ("mid", "both"):
            setup = scoring.detect_mid_setup(snap, funds.get(snap["ticker"]))
            if setup:
                out.append((snap, setup, "mid"))
    return out


def _shape(snap: dict, setup: str, tier: str, scored: dict,
           plan: dict, earnings: dict | None, extra_gaps: list[str]) -> dict:
    risks = list(scored["risks"])
    days_until = (earnings or {}).get("days_until")
    if tier == "mid" and days_until is not None and 0 <= days_until <= EARNINGS_BLACKOUT_DAYS:
        risks.append(f"{days_until} 天后财报，可能是催化剂也可能是雷")

    return {
        "ticker": snap["ticker"],
        "name": snap.get("company_name"),
        "market": snap["market"],
        "horizon": tier,
        "setup": setup,
        "setup_label": scoring.SETUP_LABELS.get(setup, setup),
        "price": snap["close"],
        "entry_zone": plan["entry_zone"],
        "stop": plan["stop"],
        "stop_pct": plan["stop_pct"],
        "targets": plan["targets"],
        "rr_ratio": plan["rr_ratio"],
        "score": scored["score"],
        "reasons": scored["reasons"],
        "risks": risks,
        "earnings": earnings or {},
        "data_gaps": sorted(set(scored["gaps"] + plan["gaps"] + extra_gaps)),
    }


def scan_swing(market: str = "US", horizon: str = "short",
               scope: str = "pool", limit: int = 15) -> str:
    """盘后扫一遍，找值得做的波段机会。

    每只入选的票都给出：为什么是现在（形态和理由）、买在哪（区间）、
    错了在哪认输（按 ATR 算的止损，不是拍脑袋的百分比）、对了到哪走
    （2 倍和 3 倍风险距离两档）。

    用法：每天盘后跑 scope="pool"；周一、周四盘后跑 scope="full"。
    不做盘前扫描——日线和期权数据收盘后才全，而且持有周期按周算。

    market:  US 美股 / CN A股
    horizon: short 短波段（3 天~2 周）/ mid 中线（2 周~2 月）/ both 两档都要
    scope:   pool 只看持仓和自选 / full 全市场
    limit:   最多返回几只，默认 15，上限 30
    """
    try:
        market = (market or "US").upper()
        horizon = (horizon or "short").lower()
        scope = (scope or "pool").lower()
        if market not in snapshot.MARKETS:
            return json.dumps({"error": f"market 只能是 US 或 CN，收到 {market}"},
                              ensure_ascii=False)
        if horizon not in HORIZONS:
            return json.dumps({"error": f"horizon 只能是 short / mid / both，"
                                        f"收到 {horizon}"}, ensure_ascii=False)
        if scope not in SCOPES:
            return json.dumps({"error": f"scope 只能是 pool 或 full，收到 {scope}"},
                              ensure_ascii=False)
        limit = max(1, min(int(limit), MAX_LIMIT))

        # ---- 1. 取候选池 ----
        if scope == "full":
            snaps = snapshot.scan(market)
        else:
            tickers = _pool_tickers(market)
            snaps = [s for s in snapshot.get(tickers, market).values() if s]
            snaps = [s for s in snaps if _passes_liquidity(s, market)]
        scanned = len(snaps)

        gaps: list[str] = []

        # ---- 2. 中线档要基本面才能判形态 ----
        funds = {}

                gaps.append("A股基本面只覆盖 150 只票且字段大多为空，"
                            "中线档的判断依据不完整")

        # ---- 3. 命中形态的才进下一步 ----
        hits = _candidates(snaps, horizon, funds)
        codes = [snap["ticker"] for snap, _, _ in hits]

        # ---- 4. 只对命中的票补消息面和资金面 ----
        earnings = catalyst.earnings_for(codes, market)
        news = catalyst.news_for(codes, days=7, min_significance="Medium",
                                 per_ticker=1)

        flows, cn_flows, boards, sentiment = {}, {}, {}, None
        if market == "US":
            flows = catalyst.options_flow(codes, days=5)
        else:
            cn_flows = cn_signals.fund_flow(codes)
            boards = cn_signals.board_of(codes)
            sentiment = cn_signals.limit_sentiment()
            gaps.append(cn_signals.BOARD_MAPPING_GAP)

        # ---- 5. 短波段排雷：财报 3 天内的直接剔除 ----
        rows = []
        for snap, setup, tier in hits:
            code = snap["ticker"]
            days_until = (earnings.get(code) or {}).get("days_until")
            if (tier == "short" and days_until is not None
                    and 0 <= days_until <= EARNINGS_BLACKOUT_DAYS):
                continue

            first_news = (news.get(code) or [None])[0]
            if tier == "short" and market == "US":
                scored = scoring.score_short(snap, flows.get(code), first_news)
            elif tier == "short":
                scored = scoring.score_short_cn(
                    snap, cn_flows.get(code), boards.get(code),
                    sentiment, first_news)
            else:
                scored = scoring.score_mid(snap, funds.get(code), first_news)

            rows.append(_shape(snap, setup, tier, scored,
                               scoring.plan_trade(snap, setup),
                               earnings.get(code), []))

        rows.sort(key=lambda r: (-r["score"], r["ticker"]))
        rows = rows[:limit]

        # ---- 6. pool 范围给最终入选的补一次实时期权流 ----
        if scope == "pool" and market == "US" and rows:
            live = catalyst.options_flow_live(
                [r["ticker"] for r in rows[:LIVE_FLOW_TOP_N]])
            for row in rows:
                flow = live.get(row["ticker"])
                if flow:
                    row["flow"] = flow

        fresh = regime.freshness(market)
        warnings = []
        if fresh["stale"]:
            warnings.append(f"{market} 行情最新只到 {fresh['latest_trading_day']}，"
                            f"距今 {fresh['days_since']} 天")

        return json.dumps({
            "market": market,
            "horizon": horizon,
            "scope": scope,
            "as_of": snaps[0]["date"] if snaps else None,
            "scanned": scanned,
            "matched": len(hits),
            "candidates": rows,
            "regime": regime.get(market),
            "warnings": warnings,
            "data_gaps": sorted(set(gaps)),
        }, ensure_ascii=False, indent=2, default=str)

    except Exception as exc:
        return json.dumps({"error": str(exc)}, ensure_ascii=False)

HORIZONS = ("short", "mid", "both")

_CN_SUFFIXES = (".SH", ".SZ", ".BJ")


def _infer_market(ticker: str) -> str | None:
    if ticker.endswith(_CN_SUFFIXES):
        return "CN"
    if ticker.isdigit():
        return None   # A股裸代码，分不清哪个交易所

def analyze_ticker(ticker: str, horizon: str = "both") -> str:
    """一只票的完整体检：趋势、点位、消息、资金、基本面。

    日线定方向、小时线定点位，两个周期一起给。中线档才展开基本面——

    horizon: short 只看短波段 / mid 只看中线 / both 两档都给（默认）
    """
    try:
        ticker = (ticker or "").upper().strip()
        if not ticker:
            return json.dumps({"error": "没给股票代码"}, ensure_ascii=False)

        if horizon not in HORIZONS:
            return json.dumps({"error": f"horizon 只能是 short / mid / both，"
                                        f"收到 {horizon}"}, ensure_ascii=False)

        market = _infer_market(ticker)
        if market is None:
            return json.dumps({
                "error": f"认不出 {ticker} 属于哪个市场。"

        if snap["stale"]:

        # ---- 小时线：只有活跃池才有 ----
        hourly = hourly_mod.hourly_setup(ticker, bars=60, market=market)
        if hourly.get("error"):
            gaps.append("这只票没有小时线数据（小时线只采持仓+自选+粗筛命中的票）")
            hourly = None

        # ---- 基本面：只有中线档才展开 ----
        fund = None
        if horizon in ("mid", "both"):

            if fund is None:

        news = catalyst.news_for([ticker], days=14, min_significance="Low",
                                 per_ticker=8).get(ticker, [])
        if not news:
            gaps.append("近 14 天没有相关新闻")

        earnings = catalyst.earnings_for([ticker], market).get(ticker)

        flow = gamma = insider = congress = cn = None
        if market == "US":
            flow = catalyst.options_flow_live([ticker]).get(ticker)
            if flow and flow.get("source") == "db":
                gaps.append("期权数据取自数据库（实时接口没取到），一天只更新两次")
            gamma = catalyst.gamma_walls([ticker]).get(ticker)
            if gamma is None:
                gaps.append("没有 gamma 墙数据（只覆盖约 40 只大盘股）")
            insider = catalyst.insider_for([ticker], days=180).get(ticker)
            congress = catalyst.congress_for([ticker], days=365).get(ticker, [])
        else:

                "market_sentiment": cn_signals.limit_sentiment(),

            if cn["fund_flow"] is None:

# 我们的规矩测试打架。
_UW_NEWS_SQL = """
select created_at, title, sentiment, is_major, tickers
from uw_news
where created_at >= now() - make_interval(hours => %s)
  and (%s::text[] is null or jsonb_exists_any(tickers, %s::text[]))
order by created_at desc
limit %s
"""


def has_reacted(snap: dict | None) -> bool | None:
    """股价对消息反应过了没有。数据不全时返回 None，不猜。"""
    if not snap:
        return None
    pct_chg = snap.get("pct_chg")
    atr_pct = snap.get("atr_pct")
    vol_ratio = snap.get("vol_ratio")
    if pct_chg is None and vol_ratio is None:
        return None
    if vol_ratio is not None and vol_ratio > REACTED_VOL_RATIO:
        return True
    if pct_chg is None or atr_pct is None or atr_pct <= 0:
        return None if vol_ratio is None else False
    return abs(pct_chg) > REACTED_ATR_MULT * atr_pct


def _scope_tickers(scope: str) -> tuple[set[str], set[str], dict[str, str]]:
    """返回 (持仓集合, 自选集合, 代码 -> 市场)。"""
    held, watched, markets = set(), set(), {}
    for row in pg.query(_POSITIONS_SQL):
        held.add(row["ticker"])
        markets[row["ticker"]] = row["market"]
    if scope in ("watchlist", "market"):
        for row in pg.query(_WATCHLIST_SQL):
            watched.add(row["ticker"])
            markets.setdefault(row["ticker"], row["market"])
    return held, watched, markets


def detect_catalysts(scope: str = "positions", hours: int = 24,
                     min_significance: str = "Medium") -> str:
    """最近出了什么事，跟我的票有没有关系，股价反应过了没有。

    每条消息都会标出「股价已经反应过了没有」——已经涨完的利好不是机会，
    是风险；纹丝不动的利好才有得做。

    scope: positions 只看持仓 / watchlist 持仓加自选 / market 全市场
    hours: 往回看几小时，默认 24
    min_significance: High 只看重大 / Medium 重大和中等（默认）/ Low 全要
    """
    try:
        scope = (scope or "positions").lower()
        if scope not in SCOPES:
            return json.dumps({"error": f"scope 只能是 positions / watchlist / "
                                        f"market，收到 {scope}"},
                              ensure_ascii=False)
        hours = max(1, min(int(hours), 24 * 14))

        held, watched, markets = _scope_tickers(scope)
        if scope == "positions":
            filter_set = held
        elif scope == "watchlist":
            filter_set = held | watched
        else:
            filter_set = None

        if filter_set is not None and not filter_set:
            return json.dumps({"scope": scope, "hours": hours, "events": [],
                               "message": "持仓和自选都是空的，没什么可看的"},
                              ensure_ascii=False, indent=2)

        wanted = sorted(filter_set) if filter_set else None

        # ---- 第一路：news 表，有重要性分级 ----
        rows = catalyst.news_recent(wanted, hours=hours,
                                    min_significance=min_significance,
                                    limit=120)
        events = []
        for item in rows:
            tickers = [t for t in item["tickers"]
                       if filter_set is None or t in filter_set]
            for code in tickers or ([None] if filter_set is None else []):
                if code is None:
                    continue
                events.append({
                    "ticker": code,
                    "event": item["title"],
                    "url": item["url"],
                    "source": item["source"],
                    "source_table": "news",
                    "sentiment": item["sentiment_label"],
                    "significance": item["significant"],
                    "published_at": item["published_at"],
                })

        # ---- 第二路：uw_news，时效更好但没有分级 ----
        for row in pg.query(_UW_NEWS_SQL, (hours, wanted, wanted, 120)):
            for code in (row["tickers"] or []):
                if filter_set is not None and code not in filter_set:
                    continue
                events.append({
                    "ticker": code,
                    "event": row["title"],
                    "url": None,
                    "source": "Unusual Whales",
                    "source_table": "uw_news",
                    "sentiment": (row["sentiment"] or "").capitalize() or None,
                    "significance": "High" if row["is_major"] else "Medium",
                    "published_at": row["created_at"],
                })

        # ---- 第三路：价格自己说的话 ----
        by_market: dict[str, list[str]] = {}
        for event in events:
            market = markets.get(event["ticker"], "US")
            by_market.setdefault(market, []).append(event["ticker"])
        snaps: dict[str, dict | None] = {}
        for market, codes in by_market.items():
            snaps.update(snapshot.get(sorted(set(codes)), market))

        for event in events:
            snap = snaps.get(event["ticker"])
            event["price_reaction"] = {
                "pct_chg": (snap or {}).get("pct_chg"),
                "vol_ratio": (snap or {}).get("vol_ratio"),
                "atr_pct": (snap or {}).get("atr_pct"),
                "reacted": has_reacted(snap),
            }
            event["held"] = event["ticker"] in held
            event["watched"] = event["ticker"] in watched
            event["_significance_rank"] = _SIGNIFICANCE_RANK.get(
                event["significance"], 3)

        # 先看是不是我的票，再看重不重要，最后「还没反应」的优先
        events.sort(key=lambda e: (not e["held"], not e["watched"],
                                   e["_significance_rank"],
                                   e["price_reaction"]["reacted"] is True,
                                   e["ticker"]))

        message = ""
        if not events:
            message = (f"最近 {hours} 小时内，"
                       f"{'持仓' if scope == 'positions' else '关注范围内'}"
                       f"没有达到 {min_significance} 级别的消息")

        return json.dumps({
            "scope": scope,
            "hours": hours,
            "min_significance": min_significance,
            "events": events,
            "message": message,
        }, ensure_ascii=False, indent=2, default=str)

    except Exception as exc:
        return json.dumps({"error": str(exc)}, ensure_ascii=False)
```

# -*- coding: utf-8 -*-
"""工具 5：持仓盯盘——我的持仓上有没有需要立刻处理的信号。

## 没事就说没事

不触发就返回空的告警列表加一句「6 只持仓，无异常」。给一堆看着热闹但不用管
的东西，等于没有盯盘——用户会开始忽略它，然后真出事的那天也一起忽略了。

所以门槛定得高：期权异动要单笔溢价 ≥ 50 万美元，或者 score 进这只票近 30 天的
前 10%（实测 NVDA 和 AMZN 的 90 分位都是 60 分）。

## 每条告警说清三件事

发生了什么、对我的仓位意味着什么、建议怎么处理。只说「NVDA 出现大额看跌期权」
是没用的——用户还得自己算这对手上 20 股意味着什么。

## UW 实时警报的坑

`/api/alerts` 返回的 `symbol` 是**期权合约代码**（`NVDA261002P00190000`），
不是股票代码；标的藏在 `meta.underlying_symbol` 里。而且 100 条里有 14 条是
`potus_schedule` 这种噪音，`symbol` 直接是 null。拿 symbol 直接跟持仓比对
会一条都对不上，必须先用 uw.underlying_of() 解出标的。

## 实时接口挂了也要能用

价格触发（跌破均线、跌破止损、创新低）和财报临近都是从库里算的，
不依赖任何外部接口。UW 那两路取不到就在 checked_sources 里少一项，
其余照常给。
"""
import json

from core import catalyst, cn_signals, scoring, snapshot, uw
from db import pg

#: 单笔期权溢价到这个数（美元）才值得打扰用户
BIG_PREMIUM = 500_000

#: 严重度。数字只用来排序。
SEVERITY = {
    "stop_breached": 95,
    "below_ma50": 80,
    "earnings_soon": 75,
    "big_bearish_flow": 70,
    "below_ma20": 60,
    "new_low": 60,
    "big_bullish_flow": 45,
    "cn_outflow": 65,
    "lhb": 50,
}

#: 财报还有几个交易日算「临近」（5 个交易日 ≈ 7 个自然日）
EARNINGS_SOON_DAYS = 7

_POSITIONS_SQL = """
select ticker, market, avg_cost, shares,
       coalesce(currency,
                case market when 'CN' then 'CNY' else 'USD' end) as currency
from user_positions
order by ticker
"""

_FLOW_RECENT_SQL = """
select ticker, opt_type, total_premium, score, sentiment, day,
       strike, expiry
from flow_alerts_archive
where ticker = any(%s)
  and day >= current_date - %s
order by total_premium desc
limit 200
"""

_FLOW_P90_SQL = """
select ticker,
       percentile_cont(0.9) within group (order by score) as p90
from flow_alerts_archive
where ticker = any(%s)
  and day >= current_date - 30
group by ticker
"""

_NEW_LOW_SQL = """
select ticker, min(low) as low_20
from stock_ohlcv_daily
where ticker = any(%s)
  and market = %s
  and date >= current_date - 40
group by ticker
"""


def is_big_flow(row: dict, p90: float | None) -> bool:
    """这笔期权异动够不够大，值不值得报。"""
    premium = row.get("total_premium")
    if premium is not None and float(premium) >= BIG_PREMIUM:
        return True
    score = row.get("score")
    if score is not None and p90 is not None and float(score) >= float(p90):
        return True
    return False


def _alert(ticker, kind, what, means, action) -> dict:
    return {
        "ticker": ticker,
        "kind": kind,
        "what_happened": what,
        "what_it_means": means,
        "suggested_action": action,
        "severity": SEVERITY.get(kind, 30),
    }


def watch_positions(hours: int = 24) -> str:
    """我的持仓上有没有需要立刻处理的信号。

    四路一起看：期权异动（A股换成主力资金）、突发消息、价格触发
    （跌破均线或止损、创新低）、财报临近。

    **没事就说没事**——不触发就返回空列表加一句话，不制造噪音。
    每条告警都会说清楚：发生了什么、对你的仓位意味着什么、建议怎么处理。

    hours: 消息和期权异动往回看几小时，默认 24
    """
    try:
        hours = max(1, min(int(hours), 24 * 7))
        rows = pg.query(_POSITIONS_SQL)
        if not rows:
            return json.dumps({"alerts": [], "checked": 0,
                               "checked_sources": ["price"],
                               "message": "没有持仓，没什么可盯的"},
                              ensure_ascii=False, indent=2)

        by_market: dict[str, list[str]] = {}
        for row in rows:
            by_market.setdefault(row["market"], []).append(row["ticker"])
        cost_of = {r["ticker"]: float(r["avg_cost"] or 0) for r in rows}
        shares_of = {r["ticker"]: float(r["shares"] or 0) for r in rows}
        currency_of = {r["ticker"]: r["currency"] for r in rows}

        snaps: dict[str, dict | None] = {}
        earnings: dict[str, dict | None] = {}
        lows: dict[str, float] = {}
        for market, tickers in by_market.items():
            snaps.update(snapshot.get(tickers, market))
            earnings.update(catalyst.earnings_for(tickers, market))
            for low_row in pg.query(_NEW_LOW_SQL, (tickers, market)):
                lows[low_row["ticker"]] = float(low_row["low_20"])

        alerts: list[dict] = []
        sources = ["price"]

        # ---- 第一路：价格触发。不依赖任何外部接口 ----
        for ticker, snap in snaps.items():
            if not snap:
                continue
            close = snap["close"]
            currency = currency_of[ticker]
            stop = scoring.position_stop(cost_of[ticker], snap)
            if stop.get("breached"):
                loss = (close - cost_of[ticker]) * shares_of[ticker]
                alerts.append(_alert(
                    ticker, "stop_breached",
                    f"现价 {close} 跌破了建议止损位 {stop['suggested_stop']}"
                    f"（依据：{stop['basis']}）",
                    f"这笔仓位当前浮亏 {loss:.0f} {currency}，"
                    "已经跌出了当初设的容错范围",
                    "按纪律该减仓或清掉。要留就得说清楚新的止损放哪、"
                    "为什么这次不一样"))
            if snap.get("above_ma50") is False:
                alerts.append(_alert(
                    ticker, "below_ma50",
                    f"跌破 50 日均线（{snap['ma_50']}）",
                    "中期趋势转弱了，波段的多头依据没了",
                    "波段仓位考虑离场；要留就当成中线仓，重新定止损"))
            elif snap.get("above_ma20") is False:
                alerts.append(_alert(
                    ticker, "below_ma20",
                    f"跌破 20 日均线（{snap['ma_20']}）",
                    "短期动能转弱，但中期趋势还在",
                    "先减一部分观察，等站回均线再补"))
            low_20 = lows.get(ticker)
            if low_20 is not None and close is not None and close <= low_20:
                alerts.append(_alert(
                    ticker, "new_low",
                    f"创 20 日新低（{close}）",
                    "没有买盘接，下跌还在延续",
                    "别在下跌途中摊平成本，先等企稳信号"))

        # ---- 第二路：财报临近 ----
        for ticker, info in earnings.items():
            days_until = (info or {}).get("days_until")
            if days_until is not None and 0 <= days_until <= EARNINGS_SOON_DAYS:
                alerts.append(_alert(
                    ticker, "earnings_soon",
                    f"{days_until} 天后财报（{info['next_earnings_date']}）",
                    "财报是掷骰子，一晚上可能跳 10% 以上，方向不可预测",
                    "波段仓位建议财报前减到能承受的量，或者干脆先出来"))

        # ---- 第三路：期权异动（美股）/ 主力资金和龙虎榜（A股）----
        us_tickers = by_market.get("US", [])
        if us_tickers:
            sources.append("options_flow")
            p90 = {r["ticker"]: r["p90"]
                   for r in pg.query(_FLOW_P90_SQL, (us_tickers,))}
            days = max(1, hours // 24 + 1)
            for row in pg.query(_FLOW_RECENT_SQL, (us_tickers, days)):
                if not is_big_flow(row, p90.get(row["ticker"])):
                    continue
                bearish = row["sentiment"] == "bearish"
                premium = float(row["total_premium"] or 0)
                alerts.append(_alert(
                    row["ticker"],
                    "big_bearish_flow" if bearish else "big_bullish_flow",
                    f"{row['day']} 有一笔 {premium / 1e4:.0f} 万美元的"
                    f"{'看跌' if bearish else '看涨'}期权"
                    f"（行权价 {row['strike']}，到期 {row['expiry']}）",
                    "有大资金在这个方向上押注，" +
                    ("跟你的多头仓位是反的" if bearish else "跟你的方向一致"),
                    "别只凭这一条动手，配合价格看——"
                    "价格同时跌破均线才是真信号" if bearish
                    else "可以作为继续持有的旁证，不构成加仓理由"))

        cn_tickers = by_market.get("CN", [])
        if cn_tickers:
            sources.append("cn_fund_flow")
            for ticker, flow in cn_signals.fund_flow(cn_tickers).items():
                if not flow:
                    continue
                net_5d = flow.get("net_5d") or 0
                if net_5d < -100_000_000:
                    alerts.append(_alert(
                        ticker, "cn_outflow",
                        f"主力 5 日净流出 {abs(net_5d) / 1e8:.2f} 亿",
                        "机构资金在持续出货，散户接盘的行情很难走远",
                        "考虑减仓，至少不要在这个位置加"))
            for ticker, records in cn_signals.lhb(cn_tickers, days=5).items():
                if records:
                    alerts.append(_alert(
                        ticker, "lhb",
                        f"近 5 天上过龙虎榜（{records[0]['reason']}）",
                        "游资在这只票上进出，波动会明显放大",
                        "把止损放宽一点或者减小仓位，别被日内波动扫掉"))

        # ---- 第四路：突发消息 ----
        all_tickers = [r["ticker"] for r in rows]
        news = catalyst.news_for(all_tickers, days=max(1, hours // 24),
                                 min_significance="High", per_ticker=1)
        if news:
            sources.append("news")
        for ticker, items in news.items():
            for item in items:
                negative = (item.get("sentiment_label") or "").lower() == "negative"
                alerts.append(_alert(
                    ticker, "bad_news" if negative else "good_news",
                    f"重大{'负面' if negative else '正面'}消息：{item['title']}",
                    "重大消息通常会改变这只票未来几天的走势方向",
                    "先看股价反应过了没有——已经跳完的消息不用再动作；"
                    "还没反应的才需要决定"))

        # ---- UW 实时警报：解出标的再跟持仓比对 ----
        if uw.available():
            live = uw.alerts(limit=100)
            if live is not None:
                sources.append("uw_alerts")
                held = set(all_tickers)
                for item in live:
                    underlying = uw.underlying_of(item)
                    if underlying and underlying in held:
                        alerts.append(_alert(
                            underlying, "big_bullish_flow",
                            f"实时警报：{item.get('name')}（{item.get('symbol')}）",
                            "你配置的扫描规则在这只持仓上触发了",
                            "去 Unusual Whales 看这条警报的细节再决定"))

        alerts.sort(key=lambda a: (-a["severity"], a["ticker"]))

        message = ""
        if not alerts:
            message = f"{len(rows)} 只持仓，无异常"

        return json.dumps({
            "alerts": alerts,
            "checked": len(rows),
            "checked_sources": sources,
            "hours": hours,
            "message": message,
        }, ensure_ascii=False, indent=2, default=str)

    except Exception as exc:
        return json.dumps({"error": str(exc)}, ensure_ascii=False)

```markdown
### UW 实时接口的两个坑

1. **必须带浏览器 User-Agent**，否则 Cloudflare 直接 403（Error 1010）。

2. **`/api/alerts` 的 `symbol` 是期权合约代码**（`NVDA261002P00190000`），
   不是股票代码，标的在 `meta.underlying_symbol` 里。

`.env` 里的键名是 `UW_T_ENDPOINT` / `UW_T_KEY`（历史遗留），
`config.py` 两个名字都认。

### A 股缺个股 → 行业的映射

`cn_universe.industry` 和 `stocks_meta.industry` 对 A股全是 NULL。
唯一带行业名的是 `cn_limit_pool_daily.industry`，只覆盖当日涨停的票。
所以板块强度只能给全市场排名，给不了「这只票所在的板块」。
补这个映射要在 tt-data-hub 做（把行业成分表灌进 `cn_universe.industry`），
不在本仓库。

### `uw_news.tickers` 是 jsonb 不是 text[]

匹配要用 `jsonb_exists_any(tickers, %s::text[])`。用 `&&` 会报
`operator does not exist: jsonb && text[]`。
（`news.related_tickers` 才是 text[]，那个用 `&&`。）
```
